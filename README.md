# アミューズメントポーカーバー向け業務管理アプリ

## アプリ概要

ポーカートーナメントとチップを用いたサイドゲームを提供するアミューズメントポーカーバー向けの業務管理アプリケーション。

来店者管理、注文・会計、トーナメント運営、サイドゲーム、スタッフのシフト・勤怠・給与管理、売上集計など、店舗運営に関わる幅広い業務を一元的に管理するためのシステム。

管理者用・現場用・ポーカーテーブル用の各端末に加え、来店者・スタッフ向けのLINE連携機能を備える。

## 主要機能

### 営業日管理
- 開店・閉店・営業日の管理
- 閉店時の未会計・未退勤・進行中トーナメントの確認

### 来店者管理
- QRコードまたは手入力による入店受付
- 来店者アカウントの作成・管理
- 入店中の来店者一覧の表示

### 注文・会計管理
- メニューの登録・編集、注文受付
- 注文状況の管理
- 会計処理と支払い方法の記録
- 会計後の返金・追加徴収などの対応

### トーナメント管理
- トーナメントの作成・スケジュール設定
- 参加者登録・座席管理
- アドオン・リエントリー・バスト処理
- ブラインドタイマー、プライズ・順位管理
- トーナメントの進行・終了管理

### サイドゲーム管理
- テーブル・座席の管理
- プレイヤーの着席・退席管理
- チップの引き出し・預け入れ
- サイドゲームの開始・終了

### スタッフ管理
- スタッフ情報の管理
- シフトの作成・申請・確認
- 出退勤・休憩の記録
- 勤怠修正申請と承認
- 月次の給与計算

### 売上管理
- 月次・日別の売上集計
- カテゴリー別・支払い方法別の売上確認
- 売上ダッシュボード

### LINE連携
- 来店者向けの入店用QRコード表示
- 来店者による注文・注文履歴確認
- トーナメント情報の確認・参加登録
- スタッフによるシフト申請・勤怠確認
- スタッフへのシフト募集通知
