# 勤怠記録タブ 表示レイアウト仕様

## 1. 目的

勤怠記録タブのテーブルを、どの端末から開いても画面幅内に収まるようにし、縦スクロールのみで全データを確認できるようにする。

---

## 2. 基本方針

- **横幅**: 画面幅に収める（横スクロールなし）
- **カラム幅**: 初回レンダリング時に画面サイズから自動計算し、以降は固定
- **カラムとデータの幅**: 各カラムについて、ヘッダーとデータセルの幅を統一
- **body 内の文字サイズ**: 全カラムで統一
- **ヘッダー（bar）内の文字サイズ**: body と統一しなくてもよい

---

## 3. カラム一覧と最小表示文字数

| カラム名   | 最小文字数 | 備考 |
|-----------|------------|------|
| 氏名      | 7 文字     | 長い名前は頭から表示し末尾を `...` で省略 |
| 勤務状況  | 4 文字     | 「勤務中」「退勤済み」 |
| date      | 10 文字    | YYYY-MM-DD 形式 |
| 出勤      | 5 文字     | HH:mm 形式 |
| 退勤      | 5 文字     | HH:mm 形式（空の場合は —） |
| 合計分    | 3 桁       | 数値 |
| 作成日時  | 8 文字程度 | M/d HH:mm 形式 |
| 更新日時  | 8 文字程度 | M/d HH:mm 形式 |
| 退勤処理  | 4 文字     | ボタン「退勤処理」 |

---

## 4. 幅の計算ロジック

1. 利用可能幅 = `MediaQuery.size.width` - 左右パディング（例: 32px）
2. 各カラムの「基準幅」を最小文字数から算出（1 文字 ≒ 10px など）
3. 合計が利用可能幅を超える場合は、各カラムを按分して調整
4. 合計が利用可能幅未満の場合は、余りを固定幅カラム（date, 日時など）に配分

---

## 5. オーバーフロー時の表示

- カラム幅を超えるテキストは、先頭から表示し、末尾を `...` で省略
- Flutter の `Text(overflow: TextOverflow.ellipsis)` を使用

---

## 6. 実装方針（採用）

- `Table` + `FixedColumnWidth` を使用
- `LayoutBuilder` で利用可能幅を取得し、重みに応じて各カラム幅を按分
- 重み: 氏名18, 勤務状況6, date10, 出勤5, 退勤5, 合計分4, 作成日時6, 更新日時6, 退勤処理5
- テキストは `overflow: TextOverflow.ellipsis` で省略
