# Phase0A 互換期間・ロールバック方針（タスク4 成果物）

作成日: 2026-03-04  
対象: D-01, D-12, D-13  
入力: [PHASE0A_BEFORE_AFTER_DECISION.md](./PHASE0A_BEFORE_AFTER_DECISION.md)

---

## 1. 互換期間

**設けない。**

- Secrets は fallback 禁止のため、旧（平文 default）と新（環境変数必須）の並存期間は設けない。
- デプロイ前に環境変数をコマンドまたはコンソールで設定済みであることを必須とし、一括切り替えで進める。env ファイルは使用しない。

---

## 2. ロールバック

**問題があれば環境変数をコマンドまたはコンソールで正しく設定し、再デプロイする。**

- 古いコード（平文 default あり）へ戻すことはしない（セキュリティ後退のため）。
- 本番で不具合が出た場合は、環境変数の誤りをコンソールまたはコマンドで修正し、再デプロイで対応する。env ファイルは使わない。
- 詳細な手順は Phase3 で Runbook に記載する（タスク8 は Phase3 実施）。
