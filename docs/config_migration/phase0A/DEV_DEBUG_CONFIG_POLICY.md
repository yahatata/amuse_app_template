# Phase0A 開発時設定ポリシー（デバッグ用）

## 1. 目的

- 本番は未設定時エラーとしつつ、開発時に毎回エラーで止まらないようにする。
- **環境変数は本番・ステージングではコマンドまたはコンソールで設定し、env ファイルは使用しない**（テンプレートリポジトリ完成・リリース開始後は絶対に使用しない）。開発段階ではローカル用に限り .env 等の利用を許容する。

## 2. 基本方針

- 本番/ステージング
  - 必須値未設定は即エラー。
  - 設定は**コマンドまたはコンソール**のみ。env ファイルは使わない。
- ローカル開発（emulator/debug）
  - **開発段階の間のみ**、ローカル設定ファイル（.env.local 等）を参照して実行可能にしてよい。
  - リリース開始後は、env ファイルは一切使わない。

## 3. 運用ルール（開発段階でローカル用 .env を使う場合）

- ローカル設定ファイルは Git 管理しない（`.gitignore` 対象）。
- リポジトリにはテンプレートのみを置く（例: `functions/env.local.example`）。
- 実ファイル（例: `functions/.env.local`）は各開発者が作成する。
- **テンプレートリポジトリが完成しリリースを始めた後は、env ファイルは絶対に使用しない。**

## 4. 記載対象（D-01 / D-12）

- `LINE_CHANNEL_ACCESS_TOKEN`
- `QR_SECRET_KEY`

## 5. 実装時ルール

- 本番判定時（production/staging）は未設定なら throw。値はコマンド/コンソールで設定されたものを参照する。
- 開発判定時（local/emulator）は、開発段階に限りローカル設定ファイルを読み込み可能にしてよい。

## 6. 注意

- ローカル設定ファイルに本番値を入れない。
- ログ出力時に token/secret を出さない。
