# Step09: 最終統合・確認・リリース判定

## このステップで実装する内容の概要

- 全ステップ統合後の動作確認、回帰確認、運用確認を実施。
- 未決事項を最終確定し、リリース判定を行う。

## 懸念・確定できていない仕様等（判断が必要）

- expectedRange 閾値の本番値。
- 旧run削除タイミングの確定。

## このステップで実装する内容全体の詳細

- 実施内容:
  - 結合テスト: 抽出 -> 計算 -> 確定 -> 支払い済み -> 通知
  - 権限テスト: admin以外拒否
  - 回帰確認: `all_staff_attendance_page` の既存機能維持
  - 実機確認: adminHome導線、CSV、通知UI
  - ドキュメント最終更新（運用手順、障害時対応）
- 完了条件:
  - 重大不具合なし
  - 未決事項の意思決定完了
  - リリース可否の合意
