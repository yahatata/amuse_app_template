# 仕様確定テンプレート（ステップ共通）

このファイルは各ステップの仕様確定ドキュメントを作成する際のテンプレートです。
各ステップの `per_step/stepXX_yyy/` フォルダ内に `SPEC.md` として作成してください。

---

## 使い方

1. このテンプレートを対象ステップの `SPEC.md` にコピーする。
2. **前ステップとの整合性確認** セクションを必ず先に記入する。
3. 各論点を1行ずつ記入し、「採用案」「根拠」「影響ファイル」を必ず埋める。
4. 完成後にレビュー依頼を行う。レビュー承認後に changeSpec 作成に進む。
