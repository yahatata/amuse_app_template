## 1. このタスクの役割

本タスクは、旧方針で作成された資料群の現状を把握し、新方針での扱いを確定するタスクである。

このタスクで決めること:
- 各旧資料の分類（残す / 再利用 / 参照用化 / アーカイブ候補）
- 各旧資料の新方針での引き継ぎ先（どの TSK / ART が吸収するか）
- 「参照用化」する資料への注記追加

このタスクで決めないこと:
- 各旧資料の本文内容の修正（参照用注記の追記のみ行う）
- 引き継ぎ先 TSK の詳細な内容（後続 TSK が担う）
- `参考_旧方針/` への物理的な移設（タイミングを見て別途実施）

---

## 4. 分類定義

| 分類 | 意味 | 対応アクション |
|---|---|---|
| `残す` | 現行のまま利用継続する | アクションなし |
| `再利用` | 後続 TSK/ART の起点として内容を引き継ぐ | 引き継ぎ先 TSK を明示する |
| `参照用化` | 積極的に更新しないが閲覧用として残す | 「この資料は参照用です」ヘッダーを追記する |
| `アーカイブ候補` | 将来的に `参考_旧方針/` へ移設する | 今は移設せず、移設候補として記録する |
