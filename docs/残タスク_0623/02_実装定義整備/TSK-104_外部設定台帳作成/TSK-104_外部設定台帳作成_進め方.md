## 1. この文書の役割

カテゴリ F 検討時叩き2 の「F-1〜F-5」を実際の作業手順として具体化する。  
実値の設定作業（インフラ作業）とはこのタスクを分けて扱う。

---

## 2. 全体の進め方

| 段階 | 目的 | この段階で行うこと | 気をつけること |
|---|---|---|---|
| 1. 対象サービス棚卸し | 何を台帳に登録するか決める | 店舗側・中央側の外部サービス一覧を作る | Secret 実値は含めない |
| 2. 設定項目草案作成 | 各サービスの設定項目を整理 | サービスごとに設定 key 名・保存先・設定方式・管理責任者候補を整理 | 「所在・方式」と「実値」を混同しない |
| 3. 確認条件の整理 | 疎通確認に必要な条件を明確にする | ART-201 の外部設定入力シートで使う確認条件を整理 | 確認の実施は TSK-201 の責務 |
| 4. 人判断 | 管理責任者・補助サービス導入判断を確定 | TBD 箇所を人が決定 | AI が判断できない権限委譲・契約判断を放置しない |
| 5. 正本反映 | ART-104.xlsx へ投入 | ChatGPT for Excel プロンプトで反映 | 構造変更と内容更新を同時依頼しない |
| 6. 説明 md 完成 | ART-104_外部設定台帳_説明.md を完成させる | 列定義・シート構成・更新ルールを埋める | Excel 正本と整合していることを確認する |

## 4. 外部サービス設定一覧の想定列

| 列名 | 内容 | 型・候補値 |
|---|---|---|
| 連番 | 行識別子 | 数値 |
| サービス区分 | LINE店舗 / LINE中央 / Secret / IAM / LIFF / Webhook / 補助 | 入力規則 |
| 設定項目名 | 設定の論理名 | 文字列 |
| 保存先 | Secret Manager / env / Firestore / 手動設定 等 | 入力規則 |
| key 名・パス | Secret key 名や env 変数名（実値ではない） | 文字列 |
| 設定スコープ | 店舗固有 / 中央共通 / 両方 | 入力規則 |
| 管理責任者 | 設定・更新の責任者 | 文字列 |
| 確認方法 | 疎通確認の方法の概要 | 文字列 |
| 営業開始前必須 | 営業開始前に設定が必須か | TRUE / FALSE |
| 備考 | Token 更新手順・注意事項等 | 文字列 |

## 5. done 条件と着手時再確認事項

done 条件:
- [ ] 店舗側・中央側の外部サービス設定項目が全件列挙されている
- [ ] Secret 実値が台帳に含まれていない
- [ ] 管理責任者・補助サービスの導入判断が確定済み
- [ ] ART-104_外部設定台帳_説明.md と Excel 正本が整合している
- [ ] `ART-902_タスク管理台帳` のステータスが `完了` に更新されている

着手時に再確認すること:
- B タスク（Secret / IAM 方針）で変更が発生していないか
- ART-101（config）との境界（外部接続 config は ART-101 か ART-104 か）が明確か
- `amuse-admin` 側の設定についても対象に含めるか確認する
