## 1. このタスクの役割

本タスクは `ART-103_業務フロー一覧.xlsx` を作成するタスクである。  
旧 D カテゴリ（`カテゴリD_業務フロー確認_テスト受入`）の検討時叩き2 の D-1 サブタスクを引き継ぐ。

このタスクで決めること:
- 業務フロー単位の一覧（Flow ID / カテゴリ / 名称 / 操作者 / 画面 / 起動 function / 営業開始必須区分）
- 各フローの完了条件と重要度
- ART-103_業務フロー一覧_説明.md の完成

このタスクで決めないこと:
- テスト観点の詳細化（TSK-201 で担う）
- 実行と記録（TSK-201 で担う）
- 不具合ループと出荷判定（TSK-201 で担う）

---

## 2. 背景

カテゴリ D 検討時叩き2 に「D-1: Flow Master の作成」として目的と観点が整理されている。  
`ART-103_業務フロー一覧` はその Flow Master に相当するが、新方針では「人が読める最小限のフロー正本」として位置づける。  
業務フロー確認の記録は ART-201 統合ワークブックが担うため、本台帳は定義正本に徹する。
