## 1. このタスクの役割

本タスクは、`ART-101_Config台帳.xlsx` を作成するタスクである。  
旧 B-1 作業の成果（`B-1_Config台帳_進め方.md` / `B-1_Config台帳_説明.md`）を引き継ぎ、新方針の ART フレームで完成させる。

このタスクで決めること:
- 対象設定群の確定（範囲固定）
- 各設定項目の定義（型・許容値・未設定時挙動・標準値・利用元等）
- AI と人の作業分担
- ART-101_Config台帳_説明.md の完成

このタスクで決めないこと:
- 環境ごとの現在値（現在値管理はこの台帳の対象外）
- Secret の実値
- ART-201 統合ワークブックの具体的な確認手順

---

## 2. 背景と着手の前提

旧 B-1_Config台帳_進め方.md に作成方針・根拠優先順位・AI/人分担が既に定義されている。  
本タスクはその内容を引き継ぎ、`TSK-101_進め方.md` に統合して実際の作業に入る。

着手開始条件:
- config 系の別軸実装・修正（A タスク）が一定程度落ち着いている
- 対象とする設定群が概ね固まっている
- `ART-101_Config台帳_説明.md` の骨格が存在している
- `ART-101_Config台帳.xlsx` の列構造が確定している
