## このフォルダの使い方

ここに置かれた資料は**正本ではありません**。  
新方針の ART/TSK フレームへの移行後も、参考として読み返せるように保存しています。

### このフォルダへ移動する対象（TSK-010 実施時）

ART-900 §11 の「新方針での扱い: 参照用に残す / 参考_旧方針へ移す」と分類された資料を移動する。

| 資料 | 現在地 | 移設予定 | 根拠 |
|---|---|---|---|
| `全体検討1.md` | `docs/残タスク_0623/` | このフォルダ | ART-900 §11.1。ART-900 が正本として確定したため |
| 各カテゴリの `検討時叩き2.md` | 各カテゴリフォルダ | このフォルダまたは各カテゴリ内に参照用として残す | ART-900 §11.3。各 TSK/ART に吸収済みのため |

### 移設の注意点

- 移設前に当該資料の先頭に「この資料は正本ではない」注記が付いていることを確認する
- 移設後、他の資料からの参照パスが壊れていないか確認する
- 削除はしない（廃止ルールに従い保存を維持する）
