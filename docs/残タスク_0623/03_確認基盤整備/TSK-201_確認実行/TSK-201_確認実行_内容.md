## 1. このタスクの役割

本タスクは `ART-201_統合ワークブック_テンプレ.xlsx` を作成し、テンプレアプリでの通し実行まで完了させるタスクである。

重要な位置づけ：

```
ART-101（Config定義）
ART-102（Function定義）   ↓ 根拠を受け取る
ART-103（フロー定義）    → ART-201（確認実行テンプレ） → 店舗別インスタンス
ART-104（外部設定定義）
```

このタスクで決めること:
- 統合ワークブックのシート構成と各シートの役割
- 検証プロファイルの定義（config 値・外部設定の組み合わせで確認内容が決まる仕組み）
- 数式ロジックの原理（入力から期待状態・実行要否を導く仕組み）
- テンプレアプリでの通し実行と結果
- 店舗別インスタンスの派生ルール

このタスクで決めないこと:
- 各定義正本（ART-101〜104）の内容（それぞれの TSK で担う）
- 店舗別インスタンスの実施内容（導入時のタスクで担う）

---

## 2. 背景

ART-900 §6 に統合ワークブックの位置づけ・シート構成・固定原則が定義されている。  
本タスクはその内容を前提として、実際の Excel テンプレを ChatGPT for Excel で作成し、テンプレアプリで通し実行する。

TSK-101〜104 が一定程度完了していることが前提。  
ただし全件完了を待たずに、Config入力・外部設定入力シートの骨格だけで着手を始められる。

---

## 3. シート構成（ART-900 §6 準拠）

| シート | 役割 | 入力主体 |
|---|---|---|
| Config入力 | ART-101 を元に採用する config 値を入力 | 人 |
| 外部設定入力 | ART-104 を元に外部設定の方式・確認状態を入力 | 人 |
| 期待値計算 | 2 入力を受けて検証プロファイル・期待状態・実行要否を計算 | 数式 |
| Gateチェック | rules / auth / secret / env / scheduler / debug 残存を横断確認 | AI先行 + 人確認 |
| Function挙動確認 | ART-102 を元に主要 function の期待挙動を確認 | AI先行 + 人確認 |
| 実機テスト | 画面・端末・認証・外部連携の実機必須項目を確認 | 人 |
| 業務フロー確認 | ART-103 を元に業務フロー単位の受入確認 | 人 |
| 判定サマリ | NG数・保留数・再確認要否を集計し go / no-go をまとめる | 数式 + 人承認 |

---

## 4. 設計固定原則（ART-900 §3.4〜3.7 から引き継ぐ）

| 原則 | 内容 |
|---|---|
| 定義正本に新定義を生やさない | ART-201 に仕様定義を書かない。定義は ART-101〜104 にある |
| 同一検証プロファイル = 同一チェック観点 | 「同一設定」ではなく「config × 外部設定 × 業務モード」の組み合わせで確認内容が決まる |
| 行は増減させず列で意味を表現 | 実行要否 / 適用状態 / 期待状態 / 非適用理由 / 結果 / 判定 で表現する |
| 数式だけを真実にしない | 数式で計算するが、どの入力が何に効くかの原理は説明 md に残す |
| GitHub Issue は前提にしない | NG有無 / NG理由 / 対応状態 / 再確認要否 / 関連メモ を各シートに持つ |
