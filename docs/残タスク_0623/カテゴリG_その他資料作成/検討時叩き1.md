# カテゴリG: そのほか資料作成 — 検討時叩き1

> 作成日: 2026-06-23  
> 目的: 営業・契約・費用関連の非技術資料に関する残タスクを整理する  
> 備考: システムの品質が固まってから着手するのが望ましい。一部は既存ドキュメント（`docs/` 配下）を元に仕上げる

## G-1: 営業資料

### 概要
潜在顧客（アミューズメントカジノ店舗）への提案・営業活動に使用する資料を作成する。

### 成果物（予定）

| 資料名 | ベース資料 | 備考 |
|------|---------|------|
| システム概要・機能紹介資料 | なし（新規作成） | スクリーンショット・デモ動画との連携も検討 |
| 人員削減効果・コスト分析資料 | `docs/人員削減効果と保守運用コスト分析.md` | 既存を仕上げる |
| 競合比較・導入メリット資料 | なし（新規作成） | 差別化ポイントの整理 |

### 残タスク
- [ ] `docs/人員削減効果と保守運用コスト分析.md` の最終版化
- [ ] システム概要・機能紹介資料の作成（機能一覧・画面キャプチャ等）
- [ ] 競合比較・導入メリット資料の作成
- [ ] 資料フォーマット・デザインの統一（スライド形式等）

---

## G-2: 契約・法務関連

### 概要
SaaS サービスとして提供するにあたり必要な法務書類を整備する。
法務専門家への相談が必要な項目を含む。

### 成果物（予定）

| 書類名 | 優先度 | 備考 |
|------|------|------|
| 利用規約（店舗向け SaaS 利用規約） | 高 | 契約前に必要 |
| 個人情報取扱い方針 | 高 | 顧客 LINE データ・個人情報の取り扱い |
| 業務委託契約書 / システム利用契約書 | 高 | 導入時に締結 |
| 保守・サポート範囲定義書 | 中 | 障害対応・アップデートの範囲明記 |

### 残タスク
- [ ] 利用規約の作成（法務確認含む）
- [ ] 個人情報取扱い方針の作成（LINE データ・スタッフ情報・顧客情報の扱いを明記）
- [ ] 契約書類の作成（法務専門家への確認推奨）
- [ ] 保守・サポート範囲の定義書作成

---

## G-3: 見積・費用関連

### 概要
導入時の初期費用・月額費用・サポート費用を定義した資料を作成する。

### 成果物（予定）

| 資料名 | ベース資料 | 備考 |
|------|---------|------|
| 工数見積書（最終版） | `docs/工数見積書.md` | 既存を仕上げる |
| 月額費用・初期費用の料金表 | なし（新規作成） | Firebase 実費・サポート費等含む |
| サポート費用の定義書 | なし（新規作成） | 対応時間・範囲・SLA 等 |

### 残タスク
- [ ] `docs/工数見積書.md` の最終版化（実績を踏まえた更新）
- [ ] 料金表の作成（Firebase 実費の見積もり含む）
- [ ] サポート費用・SLA の定義

---

## 進め方の方針
1. **G-1（営業資料）が最優先**。システムの基本機能が固まり次第、並行して進める
2. **G-2（契約書類）は初回導入前**に必ず整備する。法務専門家への相談は早めに行うことを推奨
3. **G-3（見積）は G-1 と並行**して整備し、営業活動で使用できる状態にする
4. カテゴリ F（システム資料）の完成後、資料全体を統一感のある形に整える
