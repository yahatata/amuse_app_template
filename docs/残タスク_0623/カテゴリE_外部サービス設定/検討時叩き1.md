# カテゴリE: 外部サービス・インフラ設定 — 検討時叩き1

> 作成日: 2026-06-23  
> 目的: LINE・SendGrid・Secret Manager 等の外部サービス設定タスクの概要を整理する  
> 備考: コーディング不要（または最小限）のタスクが多い。設定完了後に接続コーディング（H-5 等）と連携する

---

## E-1: LINE 関連設定（店舗アプリ用）

### 概要
各店舗の LINE 公式アカウントを作成・設定し、LIFF アプリと連携させる。
顧客向けミニアプリ・スタッフ向け LIFF の両方が対象。

### 設定項目
| 項目 | 備考 |
|-----|------|
| LINE Official Account の作成 | Messaging API チャンネル |
| LIFF アプリの登録（ユーザー用） | `public/user/` を対象 |
| LIFF アプリの登録（スタッフ用） | `public/staff/` を対象 |
| リッチメニューの設定 | 画像・アクション設定含む |
| Webhook URL の設定 | Cloud Functions のエンドポイントを指定 |
| Channel Access Token の取得 | Secret Manager への保存まで行う |

### 残タスク
- [ ] LINE Official Account の作成
- [ ] LIFF アプリ登録（ユーザー用・スタッフ用）
- [ ] リッチメニューの設定
- [ ] Webhook URL の設定と疎通確認
- [ ] Channel Access Token を Secret Manager に保存
- [ ] 設定後の実機疎通確認

### 依存関係
- D-3（LINE/LIFF 設定フローの設計）と並行して進める
- Secret Manager への保存が完了すると E-4 と連動

---

## E-2: amuse-admin 通知設定

### 概要
amuse-admin からの LINE 通知送信機能（H-5）に必要な LINE アカウント設定。
店舗用（E-1）とは別チャンネル or 同一アカウントかを要検討。

### 設定項目
- amuse-admin 用 LINE Official Account（または Messaging API チャンネル）の設定
- Channel Access Token の取得と**中央プロジェクト**の Secret Manager への保存

### 残タスク
- [ ] amuse-admin 通知用 LINE チャンネルの設定方針の決定（E-1 と同一か別か）
- [ ] Channel Access Token を中央 Firebase プロジェクトの Secret Manager に保存
- [ ] H-5（LINE 通知送信機能）の実装と連携確認

---

## E-3: SendGrid 設定（優先度低）

### 概要
エラー通知等のメール送信に使用する。LINE 通知（E-2）が優先で、こちらは補助的な位置づけ。

### 設定項目
- SendGrid アカウント作成
- 送信元メールアドレスの認証設定（ドメイン認証推奨）
- API キーの取得と Secret Manager への保存

### 残タスク
- [ ] SendGrid アカウント作成
- [ ] 送信元メールアドレス認証
- [ ] API キーを Secret Manager に保存
- [ ] amuse-admin 側の送信処理実装（H カテゴリで別途対応）

---

## E-4: 本番環境変数・Secret Manager の整備

### 概要
本番稼働に必要な環境変数・Secret が正しく設定されているかを最終確認する。
開発時の仮値・テスト用値が残っていないかのチェックが目的。

### 確認対象
| 対象 | 内容 |
|-----|------|
| `.env.production` | 全項目が本番値になっているか |
| `.env.amuse-app-template` | 同上 |
| Secret Manager（各店舗プロジェクト） | LINE Token 等が本番値で設定済みか |
| Secret Manager（中央プロジェクト） | amuse-admin 用 Secret が設定済みか |
| IAM 権限 | 各店舗 SA に必要な権限が付与されているか |

### 残タスク
- [ ] `.env` 系ファイルの全項目確認（テスト値・プレースホルダーの有無チェック）
- [ ] Secret Manager の全 Secret が本番値で設定済みか確認
- [ ] 各店舗 SA の IAM 権限付与手順の確立・ドキュメント化
- [ ] 環境変数整理（A カテゴリの実装方針に従い、基本的には環境変数を使わない方向で整理）

---

## 進め方の方針
1. **E-1 と D-3 は並行して進める**（LIFF 設定フロー設計と同時に実設定も進める）
2. **E-4 は本番リリース直前**に最終確認として実施
3. E-2 は H-5 の実装タイミングに合わせて実施
4. E-3 は最後（LINE 通知が安定してから）
