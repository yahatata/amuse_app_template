# A-4: requiredStaffByTimeSlot の本番採用

**完了（2026-06-28）** · 担当: 河合 · 依存なし

---

## このタスクは何だったか

営業スタイルごとに「何時から何時まで何人必要か」を設定し、**シフト画面表示時**に不足を警告する機能の**本番採用可否を決め、実装を完了させる**タスク。  
別エンジニアが先行実装していた機能を、方針確定・実機確認まで含めてクローズした。

---

## 結論

**本番採用で確定。** 実装済み・実機確認済み。

Admin から営業スタイルと必要人数を設定でき、**シフト画面を表示したとき**に「営業時間内に誰もいない時間帯」「必要人数を満たしていない時間帯」を警告表示する（都度計算。DB には保存しない）。

---

## 機能のイメージ

```
営業スタイル（例: 平日昼・平日夜）
  └ 営業時間 + 時間帯ごとの必要人数
       ↓
シフト画面表示時に不足判定 → 警告表示（連続時間帯はまとめて表示）
```

---

## 画面導線

```
Admin ホーム
├─ シフト（カレンダー / ドラフト）
└─ 営業日
   ├─ 営業日編集
   └─ 営業スタイル・必要人数設定  ← 今回の主画面
```

---

## データの置き場（現状）

| ドキュメント | 内容 |
|-------------|------|
| `storeMeta/businessStyles` | 営業スタイル定義（正本。旧 `config` 内の営業スタイルから移行済） |
| `storeMeta/requiredStaffByTimeSlot` | 営業スタイルごとの必要人数 |

Phase3 で営業スタイルの正本を `businessStyles` に寄せた。`requiredStaffByTimeSlot` は引き続き独立ドキュメント。

---

## 後続の検討メモ（未着手・任意）

`requiredStaffByTimeSlot` を `businessStyles` のフィールドに統合する案がある。現状は分離のまま運用しており、機能上の問題はない。
