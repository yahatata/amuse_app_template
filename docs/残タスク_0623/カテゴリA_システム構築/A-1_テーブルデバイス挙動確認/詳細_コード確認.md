| コレクション | クライアント write | 確認 |

## 3. 卓ページ（TN）操作の CF 対応

`TableDetailPage` を卓端末・terminal 共通利用。卓端末から呼ばれる主要 Callable と `role: table` 対応状況:

| 操作 | Callable | `role: table` |
|------|----------|---------------|
| 注文 | `placeOrder` | ✅（伝票 `place.table` が自卓） |
| Addon / まとめて Addon | `addon` / `bulkAddon` | ✅（`tableId` 必須・自卓一致） |
| Bust＆リエントリー / Bust&退席 | `bustAndReentry` / `bustAndExit` | ✅ |
| 空席→着席（通常/置きバケ） | `assignSeatToPlayer` / `assignOkibakeTemporaryEntryToSeat` | ✅（config 要） |
| 着席済み置きバケ操作 | `applyOkibakeAddon` / `bustOkibakeTemporaryEntry` / `linkOkibakeTemporaryEntryToBill` / `updateOkibakeTemporaryEntryLinkedUser` | ✅（`assignedTableId` が自卓） |

**config でゲート（意図的）:**

- `tableDevice.tournamentSeatAssignmentEnabled` — 空席着席（デフォルト `false`）
- `tableDevice.actionHistoryViewEnabled` — 操作履歴参照（デフォルト `true`）
- `tableDevice.actionHistoryRollbackEnabled` — 操作履歴取り消し（デフォルト `false`）

## 6. 既知の意図的差分（問題ではない）

| 項目 | 内容 |
|------|------|
| 卓ページメニュー | terminal の滞在者一覧向け項目（追加料金・会計参照等）は卓ページ UI に出ない |
