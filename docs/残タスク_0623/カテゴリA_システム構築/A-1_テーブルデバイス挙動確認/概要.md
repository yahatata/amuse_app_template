# A-1: テーブルデバイスの挙動確認

**完了（2026-06-25）** · 担当: 河合 · 依存なし

---

## このタスクは何だったか

テーブル端末（卓デバイス）とトーナメント・サイドゲームの連携が、実機・本番 rules の観点で問題ないかを確認し、足りない部分を埋めるタスク。  
コア実装は PR #131 で先行マージ済み。A-1 では**動作確認と本番化の仕上げ**が主目的だった。

---

## 結論

問題なし。実機確認・コード確認ともに想定どおり動作している。

あわせて、テーブル端末が Firestore を直接書き換えていた箇所を **Callable 経由に寄せ、rules でクライアント write を禁止**した。これにより卓端末の操作は CF 権限チェックの下で行われるようになった。

---

## やったこと（要点）

1. **実機確認** … 卓デバイス登録、TN 解除（卓側・運営側の両方向）、データ整合性
2. **Firestore rules 本番化** … `tables` / `sideGame` は read のみ。write は CF / Admin SDK のみ
3. **SG・TN 操作の CF 化** … 卓端末からのサイドゲーム操作、置きバケ関連操作を Callable に集約
4. **コード確認** … 上記変更が意図どおり配線されていることを確認

---

## 主な変更箇所

| 領域 | 参照 |
