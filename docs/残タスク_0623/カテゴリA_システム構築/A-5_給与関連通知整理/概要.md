# A-5: 給与関連通知の整理

**完了（2026-06-30）** · 担当: 河合 · B-2（Scheduler 確認）と連動

---

## このタスクは何だったか

給与まわりの通知 **9種** について、「いつ・どの重要度で出すか」を仕様として確定し、コードと食い違っていた箇所を直すタスク。  
通知の削除・統合は行わず、**9種すべて維持**する方針でクローズした。

通知は `notifications` コレクション（`operationCategory: payroll`）に保存される。

---

## 結論

| 区分 | 件数 | 実行経路 |
|------|------|---------|
| スケジューラー駆動 | 4種 | 毎日 `payrollNotificationScheduler` → `processPayrollNotifications` |
| イベント駆動 | 5種 | 計算完了/失敗・勤怠修正・hold 初回 など、事象発生時 |

---

## 仕様で変わったところ（コード反映済み）

| 通知 | 変更内容 |
|------|---------|
| `payroll_calc_remind` | `warning` で開始（現状維持）。**支払日7日前**から `strong_warning` に昇格（旧: 3日前） |
| `payroll_hold_reminder` | 毎週月曜の scheduler 通知を廃止。**hold が初めて発生したとき**のみ `registerPaymentStatus` で通知 |
| `payroll_attendance_corrected` | 「給与は自動再計算されない。再計算または差額調整を」促す文言に更新 |

その他6種は現状維持または仕様確認のみ（削除なし）。

---

## 9種の一覧（確定仕様）

### スケジューラー（毎日評価）

| triggerType | 重要度 | いつ |
|-------------|--------|------|
| `payroll_period_start` | report | 給与期間終了の翌日（計算未実行時） |
| `payroll_calc_remind` | warning → strong_warning | 督促開始日以降、計算未実行（7日前から strong） |
| `payroll_confirm_remind` | warning | 督促開始日以降、計算済みだが draft |
| `payroll_payment_overdue` | strong_warning | 支払日超過後、confirmed のまま（毎日可） |

### イベント（事象発生時）

| triggerType | 重要度 | いつ |
|-------------|--------|------|
| `payroll_hold_reminder` | report | hold 初回発生（`registerPaymentStatus`） |
| `payroll_run_completed` | report | 給与計算 run 正常完了 |
| `payroll_run_completed_with_errors` | error | run 完了だが一部失敗 |
| `payroll_run_failed` | error | run 全体の失敗 |
| `payroll_attendance_corrected` | warning | 給与反映済み勤怠の後修正 |
