## 完了した実装

- **Phase 1**: 共通ポイントID、config 検証、残高/換算 helper、新規ユーザー 6 フィールド初期化
- **Phase 2〜3**: 会計 A+B 契約、支払実績、返金・追加徴収、`pointLogs` への会計系書込、未マージ collection ロット（FIFO）
- **Phase 4**: トーナメント順位報酬（通貨型のみ）。プライズ値は基準値量、`prizeConversion` をプライズ確定時に snapshot。付与は snapshot 換算の残高量。取消は `awardedBalanceAmount` 正本。sideGameChip の `enabled` ゲート。預入・引出は残高ログ有無で replay 復旧
- **Phase 5**: A-6 初期残高（有効残高のみ UI/更新）、LINE 移行（標準 6 残高コピー）
- **Phase 6**: 表示名の config 化、通貨型履歴 UI（`pointLogs`）、analytics whitelist と未知 method 停止（cash フォールバックなし）、LIFF 残高表示（プロフィールへ配置）、Firestore index（`pointType` + `createdAt` on `pointLogs`）
- **実機確認中の追加修正**:
  - 順位報酬の直接残高加算を廃止し、基準値→残高換算へ統一
  - テンプレート編集保存時の `color: null` による Zod 失敗を修正
  - LIFF ホームの主張の強い残高表示をやめ、プロフィール（誕生日下）へ移設
- **レビュー補強**: 店舗UIの chip 表示換算を `balancePaymentSettings.sideGameChip.conversion` へ統一。カスタム会計の ByAmount 集計で chip に旧 rate 乗算していた不整合を修正

## デプロイ・確認（2026-07-26 時点）

- 対象プロジェクト: `amuse-app-template`
- Cloud Functions / Hosting / Firestore indexes: 反映済み
- Emulator 一連フロー・実機確認: 完了

## 仕様どおり未作成

- 購入 preview（`getBillPreviewTotals` 等）の chipCount 欠損時フォールバック整理（支払換算とは別概念。本タスク非必須）

## ログ・履歴の整理

- 通貨型: 新規は `pointLogs` のみ（旧 `pointALogs` / `pointBLogs` への新規書込停止）
- chip: `sideGameChipLogs` 維持
- A-6: `balanceMigrationLogs` のみ（`pointLogs` へ重複保存しない）
- 店舗向け履歴 UI: ユーザーアクション → 所持チップ・ポイント → 履歴を参照
