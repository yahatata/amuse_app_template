## ステータス

## 必須事項

1. 実装スコープの方針決定
2. 方針に基づく実装（現状維持の場合は対応なし）

## 検討事項

- 現状維持（pointA / pointB / sideGameChip のまま、表示名も変えない）
- 名前変更のみ（display name を config 化）
- 名前変更 + 種類数の追加（最大5スロット程度）

また、上記のいずれかで進める場合：
- `sideGameChip`（チップ）を名前変更の対象に含めるか（通貨型と構造が異なるため別扱いが現実的）
- 個数を増やす場合のスロット上限（現状2種 → 最大何種まで）
