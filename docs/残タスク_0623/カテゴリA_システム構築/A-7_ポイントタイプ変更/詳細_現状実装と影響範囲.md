# A-7 詳細: 現状実装と影響範囲

## 現状のポイントタイプ

現在3種類のポイントタイプが**ハードコード**されている。config による設定機能は未実装。

| タイプ | フィールドID | 性質 |
|--------|------------|------|
| ポイントA | `pointA` | 通貨型（トーナメント賞金・会計決済） |
| ポイントB | `pointB` | 通貨型（同上） |
| サイドゲームチップ | `sideGameChip` | チップ型（換算レート・専用 bill サブコレクション・異なる丸め単位） |

型リストの唯一の集約場所: `lib/globalConstant.dart`

```dart
static const List<String> pointTypes = ['pointA', 'pointB', 'sideGameChip'];
```

表示名の集約場所: `lib/core/utils/formatters.dart`（`getPaymentMethodDisplayName` の switch 文）

## sideGameChip の特殊性

`sideGameChip` は `pointA` / `pointB` と構造が根本的に異なる：
- 換算レート（`sideGameChipRate`）による yen 換算が存在する
- `bills/{billId}/sideGameChips/` という専用サブコレクションがある
- 丸め単位が通貨型と別設定
- bill の `category` としても使われている

このため、**名前変更の対象に含める場合は追加の考慮が必要**。

## スコープ別の変更量目安

### 現状維持
対応なし。

### 名前変更のみ（display name を config 化）
- 3種のフィールドIDは固定のまま
- `storeMeta/config` に `pointNames: { pointA: "xxx", pointB: "yyy" }` を追加
- Flutter の表示名参照箇所（`formatters.dart` 等 約15箇所）を config 参照に変更
- Functions 側は内部IDを使うだけなので**変更不要**
- **工数目安: 8〜12h**

### 名前変更 + 通貨型スロット追加（最大3〜5種）
- `pointC` 〜 `pointE` を固定フィールドとして追加（内部IDはコード固定）
- config で各スロットの有効/無効・表示名を設定
- `createUserAccount.ts` への初期化フィールド追加・既存ユーザーへのマイグレーション
- `accounting.ts` の Zod enum・`customPaymentValidator.ts`・payment split 計算への追加
- Flutter UI の動的リスト化（チップ除く通貨型のみ）
- **工数目安: 20〜38h**（スロット数により変動）
