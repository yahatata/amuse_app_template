## 各テーマの要点

### 1. リシート（卓数を減らすとき）

リシートと卓削除を一体化せず、次の順で運用する。

1. **使用卓選択付きリシート** … 残す卓だけ選んで全員リシート（未選択卓は空になる）
2. **卓削除** … 空卓を `removeTableFromTournament` で削除

UI: `reseat_all_dialog.dart` / CF: `reseatAllPlayers`（`reseatTableIds` パラメータ）

### 2. ブラインドタイマー

表示項目の MECE 性・正確性を確認。追加の config 化ニーズはなし。

### 3. LIFF 参加導線

LINE ミニアプリ（`public/user/`）でトーナメント閲覧・参加登録を1ページのタブ UI に整理。  
未入店ユーザーは閲覧のみ、参加登録は確認ダイアログ付き。店舗端末の運営操作はスコープ外。
