## 表示項目一覧（現行）

データソース凡例: **RT** = `views/runtime` 購読、**MAIN** = `views/main` 購読、**SNAP** = `scheduledTournaments.snapshot`（初回 `get` のみ、リアルタイム更新なし）、**CALC** = クライアント計算、**DOC** = `scheduledTournaments` ドキュメント（初回 `get`）。

| 領域 | ラベル | ソース | 備考 |
|------|--------|--------|------|
| 上部 | トーナメント名 | SNAP | `snapshot.name` |
| 中央 | 現在レベル / 開始予定時刻 | RT + CALC | 未開始時は `startAt` を `HH:mmより開始予定` 表示 |
| 中央 | ステージ残り時間 | RT + CALC | `TimerWidget` → `StageBuilder` |
| 中央 | SB / BB / Ante | RT.stages | 作成時に `sb`/`bb`/`ante` を保存。欠損時は `-`（lev 仮値 fallback 廃止） |
| 中央 | Next Blind | RT.stages + CALC | `durationSec=0` ステージはスキップ |
| 左 | Players | MAIN | `{entries+reentries-playersBusted}/{playersIn}` |
| 左 | 総エントリー | MAIN | `entries + reentries` |
| 左 | Addon | MAIN | `addons` 件数（トーナメント全体の累計） |
| 左 | Avg Stack | MAIN | `avgStack` — CF 集計。`null` は `-` |
| 左 | Reentry | MAIN | `reentries` 件数 |
| 左 | Prize | MAIN + SNAP | 入賞者数・プライズプール・順位別金額（12行/ページ、30秒ローテーション） |
| 右 | Total Time | RT + CALC | `runtime.startedAt` 基準の経過（`shiftSec`・pause 考慮） |
| 右 | Regist | DOC + RT + CALC | `regEndAt - startAt` を offset とし、`runtime.startedAt` 基準の経過秒で残り表示。締切後は「レジスト済み」 |
| 右 | Reentry情報 | SNAP | `Reentry:` プレフィックス。`maxReentries` を参照（上限回数・料金） |
| 右 | Addon情報 | SNAP | `Addon:` プレフィックス。上限回数・料金・`addonStack` |
| 右 | Next Break | RT.stages + CALC | 次 `break` までの残り。Break 中は `-` |

### 卓画面（`MainViewPanel`）にあるがタイマーに**ない**項目

`seatedCount` / `waitingCount` / `playersBusted`（単体） / `currentLevel` / `levelEndsAt` / 各種フィー。  
実機確認の結果、現場運営上は問題なし。

### タイマー表示の時刻基準

中央タイマー・Next Break・Total Time・Regist はいずれも **`runtime.startedAt` トーナメントクロック** を基準とする（`StageBuilder.elapsedSec` と整合）。pause 中は評価時刻を `pausedAt` で固定。

Regist の業務締切（LIFF / CF の参加制限）は引き続き `regEndAt` 等の壁時計・ステータスで判定。タイマー表示は運営向けの進行クロック表示。

## データ更新経路（アドオン件数・Avg Stack）

左カラム **Addon** は `views/main.addons` の累計。

| 操作 | 更新 Callable / 処理 | タイミング |
|------|---------------------|------------|
| 通常 Addon | `addon` | CF トランザクション内で `addons + 1` |
| 一括 Addon | `bulkAddon` | 処理人数分を一括加算 |
| 置きバケ Addon | `applyOkibakeAddon` | `addons + 1` |
| ロールバック | `undoAddon` / `undoBulkAddon` / `undoOkibakeAddon` 等 | 減算と同時に `avgStack` 再計算 |

**Avg Stack** は `calculateAvgStack` により CF 側で集計・書き込み。Flutter は `formatBlindAvgStack` で表示のみ。
