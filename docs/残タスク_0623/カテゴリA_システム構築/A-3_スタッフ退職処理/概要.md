# A-3: スタッフ退職処理

## ステータス
未着手（コードなし・仕様策定から必要）

---

## 必須事項

1. 退職業務モデルの方針決定（実装前に確定が必要）
2. 方針確定後の実装
   - `staffs` コレクションへの状態フィールド追加
   - 退職後の操作ブロック実装（打刻・シフト・給与確認・QR・LINE 導線）
   - 退職処理 callable の実装
   - 管理者向け退職処理 UI の実装
   - Firebase Auth 無効化・LINE リッチメニュー削除との連携
   - 再雇用フローの実装

---

## 検討事項

| 決定事項 | 選択肢 |
|---------|-------|
| 退職の業務モデル | 即日停止 / 退職予定日を登録して予定日に自動停止 |
| Firebase Auth の扱い | Auth アカウントを無効化 / アプリ側のみブロック |
| 再雇用時の UID 方針 | 同一 UID を再利用 / 新規 UID で再登録 |
| 未払い給与・未消化シフトの扱い | 退職処理前に処理必須 / 退職後も残して処理可能 |
| 個人情報（口座情報等）の保持期間 | 法令に準じた期間保持 / 削除タイミングの方針 |
