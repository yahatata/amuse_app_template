## 着手推奨順

1. **A-1**（確認のみ・すぐ着手可能）
2. **A-2**（業務定義の確定が必要な項目を先に決める）
3. **A-3**（方針決定 → 実装。最大規模のタスク）
4. **A-5**（B-2 の Scheduler 確認と合わせて実施）
5. **A-4 / A-6**（他エンジニア完了後に確認）
6. **A-7 / A-8**（方針決定のみ。実装規模は方針次第）
