# カテゴリH 残タスク 検討時叩き 1

> このファイルは `amuse-admin`（中央管理アプリ）側の残タスク概要をまとめた検討時叩き台です。  
> 店舗アプリ（amuse_app_template）ではなく、**Next.js で構築された中央監視・管理 Web アプリ側のタスク**を扱います。

---

## H-1: エラー詳細 → 重要度ルール登録ショートカット

### 概要

エラーログの詳細画面に「このエラーの重要度ルールを作成」ボタンを追加し、  
`functionEntry` / `errorKey` / `service` を自動入力した状態でルール作成画面へ遷移できるようにするショートカット機能。

### 背景・現状

現状のフロー:
1. エラー詳細画面でエラーの内容を確認
2. 別途 `/settings/importance-rules` へ移動
3. ルール作成フォームに `functionEntry` / `errorKey` / `service` を**手入力**
4. 保存

これが手間になる。

### 実装後のフロー

1. エラー詳細画面の「重要度ルールを変更」ボタンをクリック
2. `/settings/importance-rules` のルール作成画面に **`functionEntry` / `errorKey` / `service` が自動入力された状態**で遷移
3. 確認・調整して保存

### 注意点

- ルールの粒度が細かくなりすぎるリスクがある（1エラー1ルール化の防止）
- 自動入力はあくまで「入力補助」であり、保存前に内容確認を促す UI にする

### 参照ドキュメント

- `amuse-admin/docs/改善案一覧.md`（改善案 C として記載）
- `amuse-admin/src/app/(authenticated)/stores/[storeId]/errors/[logId]/page.tsx`（エラー詳細画面）
- `amuse-admin/src/app/(authenticated)/settings/importance-rules/page.tsx`（ルール作成画面）

### 想定工数

1〜2時間（AI フル利用）
