## 1. この台帳の役割

`ART-902_タスク管理台帳` は、`TSK-xxx` タスク資料の進行を管理するための台帳である。

この台帳で持つもの:
- どの TSK が存在するか
- 各 TSK の現在のステータス
- 各 TSK が対応する ART（成果物）
- TSK 間の依存関係
- 優先度と担当
- done 条件の要約

この台帳で持たないもの:
- ART 正式資料の詳細管理（→ `ART-001_資料台帳` が担う）
- 各 TSK の実施内容の詳細（→ 各 `TSK-xxx_実施まとめ.md` が担う）
- タスクの進め方手順（→ 各 `TSK-xxx_進め方.md` が担う）

---

## 2. 管理対象

登録対象: `docs/残タスク_0623` 配下に作成する全 `TSK-xxx` タスク資料

登録対象外:
- ART 正式資料（`ART-001_資料台帳` で管理する）
- 検討時叩き・一時メモ・会話ログ
- 実施まとめ・申し送りは本台帳の列として参照するが、1行を増やさない（TSK 1件 = 1行を維持）

## 4. 列定義

| 列名 | 型 | 入力規則 | 記載ルール | 記入例 |
|---|---|---|---|---|
| `TSK-ID` | テキスト | なし（手入力） | `TSK-xxx` 形式。一度採番した ID は変更しない | `TSK-101` |
| `タスク名` | テキスト | なし | 簡潔な日本語名称。ファイル名の `_内容` 前の部分と一致させる | `Config台帳作成` |
| `フェーズ` | テキスト | リスト（候補値あり） | `ART-901` の番台区分に対応するフェーズ名 | `02_実装定義整備` |
| `対応ART` | テキスト | なし | 成果として作成・更新する `ART-xxx` を `; ` 区切りで列挙 | `ART-101; ART-101_説明` |
| `依存TSK` | テキスト | なし | 先行して完了が必要な `TSK-xxx` を `; ` 区切りで列挙。なければ `該当なし` | `TSK-001` |
| `優先度` | テキスト | リスト（高 / 中 / 低） | 現時点での重要度 | `高` |
| `ステータス` | テキスト | リスト（候補値あり） | 現在の進行状態 | `進行中` |
| `内容mdパス` | テキスト | なし | `TSK-xxx_内容.md` の repo 相対パス。未作成は `TBD` | `docs/残タスク_0623/02_実装定義整備/TSK-101_Config台帳作成/TSK-101_Config台帳作成_内容.md` |
| `進め方mdパス` | テキスト | なし | `TSK-xxx_進め方.md` の repo 相対パス。未作成は `TBD` | `docs/残タスク_0623/02_実装定義整備/TSK-101_Config台帳作成/TSK-101_Config台帳作成_進め方.md` |
| `実施まとめmdパス` | テキスト | なし | `TSK-xxx_実施まとめ.md` の repo 相対パス。未作成は `該当なし` | `該当なし` |
| `申し送りmdパス` | テキスト | なし | `TSK-xxx_申し送り.md` の repo 相対パス。未作成は `該当なし` | `該当なし` |
| `担当` | テキスト | リスト（候補値あり） | 主担当。`AI` / `人` / `AI+人` | `AI+人` |
| `着手日` | 日付 | なし（YYYY-MM-DD） | 実際に作業を開始した日。未着手は空欄 | `2026-07-07` |
| `完了日` | 日付 | なし（YYYY-MM-DD） | done 条件を満たした日。未完了は空欄 | ` ` |
| `done条件サマリ` | テキスト | なし | 各 TSK の done 条件の要約（詳細は内容.md 参照） | `ART-101 作成・ART-902 ステータス更新` |
| `備考` | テキスト | なし | 依存事情、保留理由、メモなど | `A側修正完了後に着手` |

## 5. ステータス候補値

| 値 | 意味 |
|---|---|
| `未着手` | まだ着手していない |
| `着手可待ち` | 依存 TSK が完了していないため待機中 |
| `進行中` | 現在作業中 |
| `レビュー待ち` | 人の確認を待っている |
| `完了` | done 条件をすべて満たした |
| `保留` | 意図的に進めない状態 |
| `廃止` | 不要と判断して取り消した |

## 7. 更新ルール

### 7.1 新規 TSK を作成した時

1. `TSK-xxx_内容.md` を作成する
2. この台帳に 1 行追加する（`ステータス: 未着手` または `着手可待ち`）
3. `内容mdパス` と `進め方mdパス` を入力する（作成後に更新でもよい）
4. `対応ART` と `依存TSK` を入力する

### 7.2 TSK 着手時

- `ステータス` を `進行中` に変更する
- `着手日` を入力する

### 7.3 TSK 完了時

- `ステータス` を `完了` に変更する
- `完了日` を入力する
- `実施まとめmdパス` が作成済みなら入力する

### 7.4 TSK を保留・廃止する時

- 行削除ではなく `ステータス` を `保留` または `廃止` に変更する
- `備考` に理由を残す

## 8. AI が読む時のルール

AI がこの台帳を参照する必要がある場合は次の手順を取る。

1. まずこの説明 md を読む
2. ChatGPT for Excel に必要な列だけを抽出させるプロンプトを生成し、ユーザーへ渡す
3. 抽出結果は TSV 形式で受け取る（件数・抽出日時・抽出条件を含む）
4. 全件出力は避け、ステータスや対応 ART など必要な列だけを抽出する

## 10. ART-001 との役割分担

| 台帳 | 管理対象 | 管理対象外 |
|---|---|---|
| `ART-001_資料台帳` | ART 正式資料の正本所在・管理情報 | TSK、検討メモ |
| `ART-902_タスク管理台帳`（本資料） | TSK の進行状況・依存・対応成果物 | ART 正式資料の本文 |

- `ART-001` に TSK を登録しない
- `ART-902` に ART 正式資料を登録しない
- `ART-902` では、対応する ART を `対応ART` 列で参照する
