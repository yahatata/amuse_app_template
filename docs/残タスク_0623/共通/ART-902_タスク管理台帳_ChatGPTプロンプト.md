> 概要: `ART-902_タスク管理台帳.xlsx` を ChatGPT for Excel で作成するためのプロンプト集
> 主な目的: Excel 作成時の指示を標準化し、再現性を確保する
> 正本区分: md正本
> 対象: `ART-902_タスク管理台帳.xlsx` の初回作成と初期データ登録
> 更新区分: 変更時
> 参照元: `ART-902_タスク管理台帳_説明.md`; `ART-901_タスク資料作成ルール.md`
> 参照先: `ART-902_タスク管理台帳.xlsx`

---

## プロンプト 1：workbook の新規作成

このプロンプトを ChatGPT for Excel に貼り付けて実行すること。

---

```
【workbook 作成依頼】

workbook 名: ART-902_タスク管理台帳.xlsx
主シート名: タスク一覧
目的: TSK-xxx タスク資料の進行状況・依存関係・対応成果物を一元管理する台帳
1行の単位: 1タスク（TSK-xxx）= 1行

---

【列定義（列順を厳守すること）】

1. TSK-ID
   - 型: テキスト
   - 入力規則: なし（手入力）
   - 例: TSK-001

2. タスク名
   - 型: テキスト
   - 入力規則: なし
   - 例: 全体再編

3. フェーズ
   - 型: テキスト
   - 入力規則: リスト
   - 候補値: 01_再編基盤 / 02_実装定義整備 / 03_確認基盤整備 / 04_本番化実行_差分収束 / 05_導入準備整備 / 06_後続資料整備 / 07_中央管理アプリ対応

4. 対応ART
   - 型: テキスト
   - 入力規則: なし
   - 例: ART-101; ART-101_説明（複数の場合はセミコロン+半角スペース区切り）

5. 依存TSK
   - 型: テキスト
   - 入力規則: なし
   - 例: TSK-001（なければ「該当なし」）

6. 優先度
   - 型: テキスト
   - 入力規則: リスト
   - 候補値: 高 / 中 / 低

7. ステータス
   - 型: テキスト
   - 入力規則: リスト
   - 候補値: 未着手 / 着手可待ち / 進行中 / レビュー待ち / 完了 / 保留 / 廃止

8. 内容mdパス
   - 型: テキスト
   - 入力規則: なし
   - 例: docs/残タスク_0623/01_再編基盤/TSK-001_全体再編/TSK-001_全体再編_内容.md（未作成は TBD）

9. 進め方mdパス
   - 型: テキスト
   - 入力規則: なし
   - 例: docs/残タスク_0623/01_再編基盤/TSK-001_全体再編/TSK-001_全体再編_進め方.md（未作成は TBD）

10. 実施まとめmdパス
    - 型: テキスト
    - 入力規則: なし
    - 例: 該当なし（未作成または作成しない場合は「該当なし」）

11. 申し送りmdパス
    - 型: テキスト
    - 入力規則: なし
    - 例: 該当なし

12. 担当
    - 型: テキスト
    - 入力規則: リスト
    - 候補値: AI / 人 / AI+人

13. 着手日
    - 型: 日付
    - 入力規則: なし（YYYY-MM-DD 形式）
    - 未着手の場合は空欄

14. 完了日
    - 型: 日付
    - 入力規則: なし（YYYY-MM-DD 形式）
    - 未完了の場合は空欄

15. done条件サマリ
    - 型: テキスト
    - 入力規則: なし
    - 例: ART-101 作成・ART-902 ステータス更新

16. 備考
    - 型: テキスト
    - 入力規則: なし
    - 例: A側修正完了後に着手

---

【その他の要件】

- 主シートをテーブル化する（Excel テーブル機能を使う）
- 先頭行を固定する
- フィルタを有効化する
- 結合セルは作らない
- 空行・空列を構造として使わない
- 条件付き書式: ステータス列に次の色を付ける
  - 「完了」: 薄いグレー
  - 「進行中」: 薄い青
  - 「レビュー待ち」: 薄い黄
  - 「保留」「廃止」: 薄いオレンジ
  （ただし色だけに意味を持たせない。ステータス列の値を必ず確認すること）
- データ行は入れない（ヘッダー行のみで作成する）
- 補助シートは作成しない

---

【作ってはいけないもの】

- ART 正式資料の行（TSK のみ登録する）
- 結合セル
- ステータスや優先度の入力規則を外した列
- 色だけで意味を表現した列

---

【作成後に出力してほしいもの】

- 作成したテーブルのヘッダー行をテキストで確認用に出力すること
- 入力規則の候補値一覧をシート別・列別に出力すること
```

## プロンプト 2：TSK の初期登録（バッチD 用）

バッチ D で TSK-001 / TSK-010 を作成した後に使うプロンプト。  
AI が整形したデータを渡すので、それを ChatGPT for Excel に貼り付けて実行すること。

> ⚠️ このプロンプトはバッチ D 完了後に実際の TSK データを入れて使う。現時点では枠のみ。

---

```
【データ登録依頼】

workbook 名: ART-902_タスク管理台帳.xlsx
シート名: タスク一覧
目的: 以下の TSK データを「タスク一覧」シートに追加登録する
1行の単位: 1タスク = 1行

---

【登録するデータ（TSV 形式）】

TSK-ID	タスク名	フェーズ	対応ART	依存TSK	優先度	ステータス	内容mdパス	進め方mdパス	実施まとめmdパス	申し送りmdパス	担当	着手日	完了日	done条件サマリ	備考
[ここに TSV データを貼り付ける]

---

【注意事項】

- 列順はヘッダーと完全に一致させること
- 入力規則の候補値に含まれない値は入力しないこと
- 日付列（着手日・完了日）は YYYY-MM-DD 形式にすること
- 空欄は空欄のまま残すこと（「なし」などで埋めない）
- 既存行は変更しないこと
- 構造変更は行わないこと（データ追加のみ）

---

【登録後に出力してほしいもの】

- 追加した行数と各行の TSK-ID を確認用に出力すること
- 入力規則違反があれば指摘すること
```

## プロンプト 3：ステータス確認（随時用）

特定のステータスや優先度でフィルタして確認したい時に使うプロンプト。

---

```
【データ抽出依頼】

workbook 名: ART-902_タスク管理台帳.xlsx
シート名: タスク一覧
目的: [何を確認したいかを記載]
抽出条件: [例: ステータス = 「進行中」または「レビュー待ち」]
抽出列: TSK-ID、タスク名、フェーズ、対応ART、依存TSK、優先度、ステータス、担当、備考
並び順: フェーズ昇順、TSK-ID 昇順
出力形式: Markdown テーブル
件数: 全件（フィルタ後）
抽出日時: [実行日時を記載]
```
