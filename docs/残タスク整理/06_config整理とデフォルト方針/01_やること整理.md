# やること整理

## 必須タスク

1. runtime で読む設定を一覧化する
2. 各設定を「読み取れないときの扱い」で分類する
3. `storeMeta/config` と別 doc の境界を整理する
4. Functions を最終判定にする範囲を明文化する
5. docs と現行コードのズレを解消する
6. config / scheduler / requiredStaff 周辺の loader 実装を軽く整頓し、ログや fallback 理由が読みやすい状態にする

## 分類すべき観点

- デフォルトで継続してよいか
- 最後の成功値を維持すべきか
- エラー表示で止めるべきか
- 店舗ごとにデフォルトを変えるべきか
- クライアントが直接読んでよいか

## ユーザーが未記載だが必要なタスク

- **config versioning**
- **変更履歴や監査ログ**
- **Secrets と config の境界整理**
- **初期化・補完ジョブの責務整理**
- **stale docs の更新ルール**

## 完了の定義

- 主要設定が一覧化されている
- fallback 方針が設定ごとに説明できる
- store 単位差分の持ち方が決まっている
- Functions / Flutter の役割分担が明確
