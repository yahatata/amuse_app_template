# LIFFトーナメント機能

## 概要

本フォルダは、LINEミニアプリにおけるトーナメント機能の仕様検討および実装管理を行うためのドキュメントを管理する。

対象はミニアプリのトーナメント機能のみであり、店舗端末側のトーナメント運営機能は含まない。

---

## 本機能の目的

ミニアプリ利用者がトーナメント情報を閲覧し、必要に応じて参加登録を行えるようにする。

---

## 提供機能

### 閲覧

- 本日トーナメント
- 今後のトーナメント
- カレンダー表示（店舗設定で有効な場合）

### 参加登録

- 本日トーナメントへの参加登録

---

## 提供しない機能

以下は店舗端末からのみ操作可能とする。

- 置きバケ
- リエントリー
- アドオン
- バースト
- 着席
- 席移動
- トーナメント終了
- 順位確定
- プライズ確定
- その他運営操作

---

## 未入店ユーザー

未入店ユーザーもトーナメント情報の閲覧は可能とする。

ただし参加登録は不可とする。

---

## 予約機能

ミニアプリからのトーナメント予約は実装しない。

本機能で行うのは参加登録のみとする。

予約データ・仮参加データ・参加意思表明データは作成しない。
