# やること整理

## 必須タスク

1. LIFF のトーナメント操作を「参加」なのか「予約」なのか明文化する
2. 入店前ユーザーの扱いを業務ルールとして決める
3. backend で入店条件を明示的にチェックするか決める
4. frontend の表示・文言・ボタン制御を新ルールに合わせる
5. no-show やキャンセル時の扱いを決める

## ユーザーが未記載だが必要なタスク

- **二重押下・再送対策**
- **定員到達時の待機列ルール**
- **入店後に予約を参加へ昇格させる処理**
- **bill をまだ持たない人への課金タイミング**
- **トーナメント一覧自体を未入店にも見せるか**

## 完了の定義

- 入店前ユーザーが何をできるかが明確
- 課金タイミングが一意に決まっている
- frontend と backend が同じルールで止める
- 現場で説明しやすい導線になっている
