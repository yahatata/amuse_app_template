# やること整理

## 必須タスク

1. 実デプロイ済み Cloud Scheduler job の一覧と設定を確認する
2. `schedulerSupervisor` の最新成功ログを確認する
3. `storeMeta/schedulerConfig` とコードの jobKey が一致しているか確認する
4. supervisor が enqueue した task が各 queue へ正しく入るか確認する
5. 失敗時ログの見え方と復旧手順を確認する
6. loader / dispatch log 実装で、原因追跡しづらいログの乱れがないか確認する

## ユーザーが未記載だが必要なタスク

- **監視対象と通知方法の決定**
- **job ごとの担当オーナー決め**
- **再実行の標準手順整備**
- **timezone ズレ確認**
- **stale docs の更新**

## 完了の定義

- schedulerSupervisor の役割と設定が実環境で確認できている
- 主要 job が予定どおり enqueue される
- 失敗時にどこを見るか決まっている
- Cloud Tasks 側の downstream 検証へ引き継げる
