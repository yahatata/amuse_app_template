# やること整理

## 必須タスク

1. 退職の業務定義を決める  
   即日停止なのか、退職予定日を登録するのかを決める必要があります。
2. `staffs` の状態管理を設計する  
   active / retired / suspended のような状態をどう持つかを決めます。
3. 退職後に停止すべき操作を洗う  
   打刻、シフト、給与確認、QR 利用、LINE 導線などです。
4. 過去データ保持方針を決める  
   勤怠、給与 run、通知、口座情報などをどう残すかが必要です。
5. UI と管理フローを作る  
   管理者が退職処理をどこから行うかを決める必要があります。

## ユーザーが未記載だが必要なタスク

- **未払い給与や保留支払いの扱い**
- **未消化シフト申請や将来シフトの扱い**
- **QR / 認証 / リッチメニューの無効化**
- **再雇用時の扱い**
- **個人情報をどこまで残すか**

## 完了の定義

- 退職後に何が使えて何が使えないかが明確
- 過去の勤怠・給与履歴を壊さない
- 管理者が迷わず退職処理できる
- 再雇用や誤操作時の戻し方針がある
