# やること整理

## 必須タスク

1. 現行仕様のまま本番採用する価値を判断する
2. 実環境で scheduler → task → notification 作成の動作を確認する
3. admin 側の通知閲覧導線が実用的か確認する
4. 通知の重複防止、停止条件、strong warning 昇格条件を確認する
5. 省略するなら代替運用を決める

## ユーザーが未記載だが必要なタスク

- **通知の既読・保留運用ルール**
- **古い通知の TTL / 表示期間**
- **給与計算そのものとの責務分離確認**
- **現場が本当にこの通知を必要としているかの確認**

## 完了の定義

- 採用 / 省略 / 簡略化 の方針が決まっている
- 採用するなら end-to-end で動作確認済み
- 省略するなら代替手段が決まっている
