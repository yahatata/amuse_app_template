## 1. 実装の前提

- `tobe_spec` を正本とし、ここでは実装へ落とし込む単位で整理する
- `tableDevice` は顧客端末ではなく、店舗従業員用の卓端末として扱う
- `tables/{tableId}` を卓状態の単一参照先にする
- サイドゲーム時の `tables.status` は固定値ではなくゲーム名を使用する
- `tableDeviceRegistrationEnabled` と `forceClearPasscode` は `storeMeta/config` を参照する

## 3. 実装時の重要ルール

### 3.1 `tournamentDetail` を雑に扱わない

`tournamentDetail` は UI 表示用のおまけではなく、卓 Home が `tables/{tableId}` を単一参照先にするための中核データである。  
追加だけでなく、解除・終了・sideGame 往復時の整合を必ず揃える。

### 3.2 sideGame の保存先を揃える

sideGame 開始時は次を同時に整える。

- `tables.status = gameName`
- `sideGame.gameName = gameName`
- `sideGame.active = true`

これを揃えないと、現行実装と同じ不整合が残る。

### 3.3 `tablesSeat.isEnabled` は横断対応する

`removeTableFromTournament` だけ変えても不十分。  
一覧・絞り込み・削除対象選択の各 UI が `isEnabled` を見なければ、論理削除が崩れる。

### 3.4 `role: table` と `terminal` の責務を混ぜない

`table` ロールは `terminal` の一種として扱わず、ルーティング・紐付け・権限の意味を明確に分ける。

## 5. 実機確認計画

実機確認は、**1 回の操作で複数項目をまとめて確認できる手順**を優先する。

### 5.1 確認セット A: `table` 端末登録と卓紐付け

ユーザー操作:

1. 新規端末を `role: table` で登録する
2. admin 端末で対象端末に卓紐付けを設定する
3. 端末を再起動または再遷移する

同時に確認すること:

- `table` ロールで登録できる
- `devices.optionParams.table_device_table.tableId` が保存される
- `tableId` 未設定時は案内メッセージになる
- 紐付け後は卓専用 Home に入る

Cursor 側確認:

- `devices` ドキュメント
- SharedPreferences に依存する再遷移結果

### 5.2 確認セット B: トーナメント登録 / 解除

ユーザー操作:

1. 卓デバイスからトーナメント登録する
2. 卓 Home からトーナメント画面へ入る
3. 卓デバイスから登録解除する

同時に確認すること:

- `tables.status = 'tournament'`
- `tables.tournamentDetail` が入る
- `tablesSeat.isEnabled = true / false` が切り替わる
- 論理削除後に `TournamentSelectPage` / `TableSelectPage` 側で残骸表示されない

Cursor 側確認:

- `tables`
- `scheduledTournaments/{id}/tablesSeat/{tableId}`

### 5.3 確認セット C: サイドゲーム開始 / 終了

ユーザー操作:

1. 卓デバイスからゲーム名を選んで sideGame 開始
2. sideGame 画面に入る
3. sideGame 終了を行う

同時に確認すること:

- `tables.status = gameName`
- `sideGame.gameName = gameName`
- `sideGame.active = true / false`
- `tournamentDetail` がある場合は終了後 `status = 'tournament'`
- `tournamentDetail` がない場合は終了後 `status = 'open'`

Cursor 側確認:

- `tables`
- `sideGame/{tableId}`

### 5.4 確認セット D: config 切り替え

ユーザー操作:

1. `tableDeviceRegistrationEnabled` を `true / false` で切り替える
2. 卓デバイス Home を確認する
3. 強制解除ダイアログでパスコード入力を試す

同時に確認すること:

- 登録ボタンの表示 / 非表示が切り替わる
- `forceClearPasscode` が UI 判定に反映される

Cursor 側確認:

- `storeMeta/config`
