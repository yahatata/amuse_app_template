# やること整理

## 必須タスク

1. Functions を `live` / `legacy` / `parked` / `unknown` に分類する
2. `index.ts` export と実運用 docs の整合を確認する
3. `unused_function_lib` に置いている理由を一覧化する
4. 本当に不要なものだけ削除候補へ移す
5. stale docs を更新する

## ユーザーが未記載だが必要なタスク

- **削除前の最終確認手順**
- **remote にだけ残る function の確認**
- **クライアントから呼ばれていないかの再監査**
- **legacy source の保管方針**

## 完了の定義

- live と legacy の線引きができている
- `unused_function_lib` の意味が説明できる
- 削除候補が明確
- docs と実コードのズレが減っている
