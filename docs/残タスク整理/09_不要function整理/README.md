# 不要function整理

## このタスクの要点

「不要な function が残っている」は半分正しく、半分は整理の問題です。  
現状は、意図的に退避されたもの、古い docs にだけ残っているもの、実運用確認が必要な legacy が混在しています。

## 現状整理

- `functions/src/unused_function_lib/` という退避場所がある
- `functions/src/index.ts` からはそこは export されていない
- つまり、少なくとも現エントリーポイント上はデプロイ対象外
- 一方で古い docs には、現在のコード構成とずれる記述もある

## いま言える状態評価

- 単純削除フェーズではない
- まず分類が必要
- docs の鮮度問題も同時にある

## このタスクの本質

本質は「ファイルを減らすこと」ではなく、何が live で何が legacy かを誰でも説明できる状態にすることです。
