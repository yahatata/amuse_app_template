# やること整理

## 必須タスク

1. queue 一覧を現行コードと実環境で照合する
2. 各 queue の consumer function、region、SA を確認する
3. 既存 pending / retry task の中に壊れたものが残っていないか確認する
4. payload 形式が consumer の期待と一致しているか確認する
5. 代表フローを実行し、enqueue から完了まで確認する

## ユーザーが未記載だが必要なタスク

- **削除対象 task の基準決め**
- **manual replay 手順整備**
- **retry 方針の確認**
- **dispatch deadline / timeout の妥当性確認**
- **運用ログの検索キー整理**

## 完了の定義

- 主要 queue が実環境で確認できる
- 旧 malformed task の扱いが決まっている
- 代表業務フローで enqueue から実行完了まで確認できる
- 障害時の確認手順が残る
