# やること整理

## 必須タスク

1. 現場で必要人数判定を本当に使うか確認する
2. 今の hourly slot 仕様で十分か確認する
3. weekday / event / 臨時営業への対応方針を決める
4. 編集導線と運用責任者を決める
5. 不足判定を何に使うかを決める

## ユーザーが未記載だが必要なタスク

- **empty array の運用意図確認**
- **必要人数変更履歴の要否**
- **営業時間変更との整合**
- **シフト不足アラートや可視化との連携**

## 完了の定義

- 残すかやめるかが決まっている
- 残すなら粒度と運用方法が決まっている
- 使い道が明確になっている
