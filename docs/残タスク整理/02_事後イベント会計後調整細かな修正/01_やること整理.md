# やること整理

## まずやること

1. 会計後調整に関する細かな残件を1つの一覧に集約する
2. 各残件を `blocking` / `本番前に直したい` / `後続でよい` に分類する
3. 現在の docs と現行コードの不一致を洗う
4. 旧導線・旧ラベル・旧 callable の残りを見つける

## 実際に想定される残件

- 旧 `postEvent*` 系や旧 dialog の残置整理
- 旧ラベルや旧画面名の混在確認
- 実機確認 docs の未記入箇所の整理
- analytics rollback の最終確認
- Firestore rules / index まわりの微調整
- ログ文言やエラーハンドリングの整え

## ユーザーが未記載だが必要なタスク

- **残件管理の置き場決め**  
  docs に残すのか、issue 化するのか、1回きりのチェックリストにするのかを決める必要があります。
- **「今は直さない」ものの明文化**  
  小さな違和感を全部 blocking にすると進行が止まるので、あえて後続に回すものを明示する必要があります。
- **差分の棚卸し**  
  会計後調整まわりは変更量が多いため、未コミット差分の意図確認も必要です。

## 完了の定義

- 細かな残件が1か所にまとまっている
- blocking / 非 blocking が分かれている
- 本番前に残せないものに優先順位が付いている
- 「これは今回やらない」が明文化されている
