# 事後イベント会計後調整細かな修正

## このタスクの要点

会計後調整の大枠は進んでいますが、その過程で出てきた細かなズレや残件が散らばっています。  
このタスクは「新仕様の追加」よりも、「本番前に細部を整え、残件をひとつの管理単位にまとめる」ことが中心です。

## 現状整理

- 細かな残件は既存 docs の各所に分散しています。
- 旧ラベルや旧導線の残り、実機確認の未記入、analytics 周辺の運用確認、legacy path の整理などが混ざっています。
- つまり、現状は「残件がない」のではなく「残件が1か所にまとまっていない」状態です。

## いま言える状態評価

- 課題の見つかり方: 分散している
- 緊急度: 個別には小さく見えるが、総量としては無視しにくい
- ゴール: 仕様追加ではなく、出荷前の残件収束

## このタスクの本質

本当に必要なのは「細かな修正をすること」よりも、次の2つです。

1. 何が blocking で、何が後回し可能かを分類すること
2. 本番前に残してはいけない微細不整合をつぶすこと
