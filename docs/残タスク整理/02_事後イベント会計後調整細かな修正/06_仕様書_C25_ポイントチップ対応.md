## 前提知識・単位定義

| フィールド | 単位 | 備考 |
|---|---|---|
| `methodBreakdown.amountIncl` | **円（yen）** | UI 入力値・callable 送受信値すべて円 |
| `users.sideGameChip` | **枚数（chip count）** | ユーザー残高 |
| `users.pointA` / `users.pointB` | **円（yen）** | ユーザー残高 |
| `paymentTotals.sideGameChip` | **円（yen）** | 元の会計での支払い額 |
| `paymentTotals.pointA/pointB` | **円（yen）** | 同上 |

特殊メソッドの残高更新換算:
- `sideGameChip`: `chipDelta = Math.floor(yenAmount / chipRate)` （枚数で管理）
- `pointA` / `pointB`: `pointDelta = Math.floor(yenAmount)` （円で管理）

#### (C) 返金バリデーション（`cashActionType === 'refund'` かつ methodBreakdown にいずれかのメソッドが含まれる場合）

対象: **全メソッド**（non-special も special も）

```ts
if (cashActionType === 'refund') {
  // paymentTotals を billData から取得
  const paymentTotals: Record<string, number> = (billData.paymentTotals as Record<string, number>) ?? {};

  // 当 cycle の全 cashActions を読み込んで返金済み金額を集計
  const allCashActionsSnap = await tx.get(cashActionsCollectionRef);
  const alreadyRefundedByMethod: Record<string, number> = {};
  for (const caDoc of allCashActionsSnap.docs) {
    const caData = caDoc.data();
    if (caData.cashActionType !== 'refund') continue;
    const breakdown = Array.isArray(caData.methodBreakdown) ? caData.methodBreakdown : [];
    for (const entry of breakdown) {
      const m = entry.method as string;
      alreadyRefundedByMethod[m] = (alreadyRefundedByMethod[m] ?? 0) + (entry.amountIncl as number ?? 0);
    }
  }

  // 各メソッドの返金可能上限を検証
  for (const entry of methodBreakdown) {
    const method = entry.method;
    const originalPaid = paymentTotals[method] ?? 0;
    const alreadyRefunded = alreadyRefundedByMethod[method] ?? 0;
    const remainingRefundable = originalPaid - alreadyRefunded;
    if (entry.amountIncl > remainingRefundable) {
      throw new FunctionCustomError({
        errorKey: 'ACCOUNTING_CASH_ACTION_INVALID',
        message: `${method} の返金可能額を超えています。返金可能残額: ¥${remainingRefundable}、要求額: ¥${entry.amountIncl}`,
        context: { billId, method, originalPaid, alreadyRefunded, requested: entry.amountIncl },
      });
    }
  }
}
```

#### (D) 追加徴収時の残高確認（`cashActionType === 'collection'` かつ特殊メソッドあり）

```ts
if (cashActionType === 'collection' && hasSpecial && userDoc) {
  const userData = userDoc.data()!;
  for (const entry of specialMethodEntries) {
    const method = entry.method as SpecialMethod;
    const requiredBalance = method === 'sideGameChip'
      ? Math.floor(entry.amountIncl / chipRate)
      : Math.floor(entry.amountIncl);
    const currentBalance = (userData[method] as number) ?? 0;
    if (currentBalance < requiredBalance) {
      const unit = method === 'sideGameChip' ? '枚' : '円';
      throw new FunctionCustomError({
        errorKey: 'ACCOUNTING_CASH_ACTION_INVALID',
        message: `${method} の残高が不足しています。残高: ${currentBalance}${unit}、必要: ${requiredBalance}${unit}`,
        context: { billId, userId, method, currentBalance, requiredBalance },
      });
    }
  }
}
```

#### (E) write ステップへのユーザー残高更新追加

ステップ10（`tx.update(billRef, ...)` の後）に追加:

```ts
if (hasSpecial && userRef) {
  const balanceUpdates: Record<string, any> = {
    updatedAt: FieldValue.serverTimestamp(),
  };
  for (const entry of specialMethodEntries) {
    const method = entry.method as SpecialMethod;
    const delta = method === 'sideGameChip'
      ? Math.floor(entry.amountIncl / chipRate)
      : Math.floor(entry.amountIncl);
    if (delta > 0) {
      // collection: 差し引き、refund: 加算
      const sign = cashActionType === 'collection' ? -1 : +1;
      balanceUpdates[method] = FieldValue.increment(sign * delta);
    }
  }
  if (Object.keys(balanceUpdates).length > 1) {
    tx.update(userRef, balanceUpdates);
  }
}
```

String _buildMethodLabel(String method) {
  final chipRate = StoreConfigService.instance.latestData?.sideGameChipRate
      ?? kDefaultSideGameChipRate;
  final max = (_paymentTotals[method] ?? 0) - (_alreadyRefundedByMethod[method] ?? 0);

  switch (method) {
    case 'sideGameChip':
      final chips = (max / chipRate).floor();
      return 'ゲームチップ（最大: $chips枚 / ${max}円相当）';
    case 'pointA':
      return 'ポイントA（最大: ¥$max）';
    case 'pointB':
      return 'ポイントB（最大: ¥$max）';
    default:
      return '${_methodLabel(method)}（最大: ¥$max）';
  }
}

## 5. テスト方針

### Functions（ユニットテスト）

対象: `recordPostSettlementCashAction.ts`

| テストケース | 確認内容 |
|---|---|
| collection + sideGameChip, 残高十分 | cashAction 保存、users.sideGameChip が chipDelta 減算される |
| collection + sideGameChip, 残高不足 | `ACCOUNTING_CASH_ACTION_INVALID` で拒否 |
| refund + sideGameChip, 初回返金 | cashAction 保存、users.sideGameChip が chipDelta 加算される |
| refund + cash, ポイント支払い分を超える返金 | `ACCOUNTING_CASH_ACTION_INVALID` で拒否 |
| refund + cash, 2回目で上限超え | 1回目は OK、2回目は拒否 |
| party.userId なしで special method | `ACCOUNTING_CASH_ACTION_INVALID` で拒否 |

### 実機確認

| 確認項目 | 手順 |
|---|---|
| 確認1 | ポイントA での追加徴収 → users.pointA が正しく減算されているか |
| 確認2 | sideGameChip での追加徴収 → users.sideGameChip（枚数）が正しく減算されるか |
| 確認3 | sideGameChip での返金 → users.sideGameChip（枚数）が正しく加算されるか |
| 確認4 | 現金 4,000円 + ポイントA 3,000円 払い → 現金 5,000円返金は拒否されるか |
| 確認5 | 現金 4,000円 返金後、再度 現金 1,000円返金 → 拒否されるか（上限 4,000円）|
