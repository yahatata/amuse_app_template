## 10. 正常と判断する条件（運用時・2026-06-02 固定）

Phase 7 Step 1。技術正本は §1〜9、**運用時の読み方**は `amuse-admin` の [定期実行タスク正常系定義](../../../amuse-admin/docs/運用時資料/定期実行タスク正常系定義.md) に集約。

### 10.1 共通 PASS 連鎖（再掲）

enabled な各 job について:

```
schedulerSupervisor（03:00 JST）
  → ① タスク作成: enqueued または説明可能な skip
    → ② 本処理: execution completed / skip（plannedRunAt + grace 内）
      → downstream（該当時）: child ② 完了または理由付き skip
```

層 A・B のみでは **正常とみなさない**（[06_ログと検知方針.md](./06_ログと検知方針.md) §1）。

### 10.2 中央管理アプリでの見方

| 画面 | 正常の目安 |
|------|-----------|
| HOME / Scheduler 列 | 当日分の異常件数が極端でない |
| 店舗詳細 > Scheduler 監視 | 6 job が当日 `planningDate`、① が `予約成功`/`予約不要`、② が時刻に応じ `実行予定`/`完了`/`実行スキップ` |
| 同上 child セクション | 下位タスクの ①② が追える。根拠不明の `開始未到達` が並ばない |
| 店舗詳細 > Task 監視 | 実行された child handler が success / 自然な実行中 |

### 10.3 異常とみなす代表例

- 04:05 JST 以降の `supervisor_missing`（当日 supervisor 未記録）
- `plannedRunAt` + grace 超過後も ② `開始未到達`
- child 生成があるはずなのに child セクションが空
- LINE scheduler 異常通知と画面状態の不一致

### 10.4 job 別の補足

| jobKey | 正常 / skip の典型 | 自然確認のタイミング |
|--------|-------------------|---------------------|
| `weeklyPlanner` | assessment child または skip | 毎週木 04:40 JST 以降 |
| `generateRecurringTournamentsByScheduler` | Firestore 生成または skip | 毎週木 04:50 JST 以降 |
| `enqueueTournamentTasksByScheduler` | tournament child または skip | 毎日 05:00 JST 以降 |
| `scheduledCleanup` | cleanup 完了または対象なし skip | 毎日 05:00 JST 以降 |
| `payrollNotificationScheduler` | `processPayrollNotifications` まで | 毎日 05:00 JST 以降 |
| `scheduleGenerateNextYearBusinessHours` | 年次 enqueue | **1/29 のみ**自然。他は手動投入 |
