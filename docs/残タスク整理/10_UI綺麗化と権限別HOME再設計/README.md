# UI綺麗化と権限別HOME再設計

## このタスクの要点

現状の HOME は、見た目の問題だけでなく、情報設計と権限制御の問題を抱えています。  
とくに `terminalHomePage` は、非 admin でもかなり多くの導線が見えてしまいやすい構造です。

## 現状整理

- `terminalHomePage.dart` に多くのボタンが並ぶ
- `optionKeys: null` のボタンは常時表示
- 非 admin でも `_deviceOptions.isEmpty` なら全表示
- title も `Terminal ホーム` のまま

## いま言える状態評価

- 機能はある
- 本番向け UX と権限 UX は未整理
- redesign の主目的は「きれいにする」より「安全でわかりやすくする」

## このタスクの本質

このタスクはデザイン改修だけではありません。  
本質は「どのデバイスで、誰に、何を最初に見せるか」を再設計することです。
