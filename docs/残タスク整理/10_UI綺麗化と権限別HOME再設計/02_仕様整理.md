# 仕様整理

## ほぼ確定でよい仕様

### 1. 権限表示は deny-by-default に寄せるべき

現状の「options が空なら全表示」は、開発中は便利でも本番では危険です。  
本番運用では、権限が明示されていないものは見せない方向が自然です。

### 2. HOME は役割別に最適化した方がよい

admin と terminal が同じ密度の HOME を共有すると、情報過多になりやすいです。  
役割別 HOME を持つ方向が自然です。

### 3. test / debug 導線は本番導線から分離すべき

現状ボタン群には本番業務以外の導線も混じっているため、分離はほぼ必須です。

## ユーザー判断が必要な仕様

### 1. 未設定非 admin 端末の扱い

選択肢:

1. 何も見せず設定待ちにする
2. 最低限の一般機能だけ見せる
3. 現状どおり広めに見せる

おすすめは 1 か 2 です。  
本番安全性を考えると 3 は避けたいです。

### 2. ダッシュボードの可視性

選択肢:

1. admin のみ
2. 一部 terminal にも開く

売上系は 1 寄りが安全です。

### 3. HOME の分け方

候補:

1. adminHome / terminalHome / tableHome を完全分離
2. 共通 shell + 権限別カード表示

大規模運用まで見据えるなら 1、保守性を優先するなら 2 です。
