# やること整理

## 必須タスク

1. デバイス種別ごとのペルソナを整理する
2. admin / terminal / table などの初期 HOME を再設計する
3. 各ボタンの表示条件を整理する
4. test / debug / legacy 導線を本番 HOME から外す
5. HOME から辿る代表業務導線を最短化する

## ユーザーが未記載だが必要なタスク

- **未設定端末の初期表示**
- **エラー時や権限不足時の表示**
- **店舗状態表示の置き方**
- **設定画面や危険操作の隠し方**
- **スマホ / タブレットでの一覧性**

## 完了の定義

- デバイスごとに見えるべき情報が整理されている
- 権限がない操作は見えないか、少なくとも誤解されにくい
- HOME から主要業務へ迷わず行ける
- test / legacy 導線が本番ホームから分離されている
