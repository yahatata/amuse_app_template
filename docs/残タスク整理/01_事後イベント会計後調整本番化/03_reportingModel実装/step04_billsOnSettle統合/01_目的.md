# Step 04: billsOnSettle への統合

## このステップの目的

最も影響範囲が大きい `billsOnSettle` トリガーに reporting 書き込みを組み込む。  
このステップが正しく動けば、通常会計・carryover（翌日以降会計）・resettle（reopen 後の再会計）のすべての settle エントリが自動的に作成される。

> **重要:** `billsOnSettle` は Firestore trigger（onDocumentUpdated）のため、callable と異なりエミュレータまたは実機での確認が必須。AI のユニットテストは**部分的なカバレッジ**に留まることを前提として進める。

## 変更の概要

`billsOnSettle` の既存の `enqueueSettlement`（analytics）呼び出しの直後に、同じ feature flag パターンで reporting 書き込みを追加する。

```typescript
// 既存（変更しない）
if (storeConfig.features?.settlementAggregatorEnabled) {
  await enqueueSettlement(billDoc);
}

// 追加（新規）
if (storeConfig.features?.reportingAggregatorEnabled) {
  const behavior = await loadTaxReportingBehavior();
  const entry = buildSettleEntry({ billId, cycleNo, billData, behavior });
  await writeReportingEntry(db, entry);
  await applyEntryToReportingMonthly(db, entry);
}
```

**settle / resettle の判定:**  
`cycleNo === 1` の場合は `entryType = "settle"`、`cycleNo > 1` かつ reopen 後の場合は `entryType = "resettle"`。

## テスト方針

### AI が実行するテスト（ユニット）

既存の `bills.onSettle.spec.ts` に以下のケースを追加する。

| ケース | 確認内容 |
|---|---|
| `reportingAggregatorEnabled = true` のとき | `writeReportingEntry` と `applyEntryToReportingMonthly` が呼ばれるか（mock） |
| `reportingAggregatorEnabled = false` のとき | 上記関数が呼ばれないか |
| `reportingAggregatorEnabled` が未設定のとき | 上記関数が呼ばれないか |
| reporting の書き込みが失敗したとき | trigger 全体がエラーにならないか（analytics と同様のエラー吸収） |
| 既存テストが全件 PASS すること | 既存動作を壊していないか |

### 実機確認（このステップで必須）★

**エミュレータまたは実機で確認すること:**

1. `reportingAggregatorEnabled = true` の storeMeta/config を設定する
2. テスト用の bill を会計完了（`status: settled` に遷移）させる
3. 以下を Firestore で確認する:
   - `reportingEntries/{billId}_settle_1` が作成されているか
   - `categoryBreakdown` / `paymentBreakdown` / `categoryPaymentMatrix` の値が正しいか
   - `reportingMonthly/{yyyyMM}` が作成・更新されているか
   - `aggregationMarkers/entries_{entryId}` が作成されているか
4. 同じ bill を再度 trigger させたとき（冪等性テスト）:
   - `reportingEntries` のドキュメントが重複していないか
   - `reportingMonthly` が二重加算されていないか

**確認に使用する実データの指定方法:**  
Firestore コンソールまたは Firebase CLI（`firebase firestore:get`）で上記ドキュメントを確認する。
