## 変更の概要

```typescript
if (reportingEnabled) {
  // 元の settle エントリを読んで符号反転
  const originalEntryId = `${billId}_settle_${cycleNo}`;
  const originalEntry = await readReportingEntry(db, originalEntryId);
  if (originalEntry) {
    const rollbackEntry = buildReopenRollbackEntry({
      billId, cycleNo, reopenExecutedAt, originalSettleEntry: originalEntry
    });
    await writeReportingEntry(db, rollbackEntry);
    await applyEntryToReportingMonthly(db, rollbackEntry);
  }
}
```

**元の settle エントリが存在しない場合:**  
reopen 実装当初（feature flag が OFF だった期間）は settle エントリが存在しない可能性がある。  
その場合は rollback エントリの書き込みをスキップし、ops ログに記録する。
