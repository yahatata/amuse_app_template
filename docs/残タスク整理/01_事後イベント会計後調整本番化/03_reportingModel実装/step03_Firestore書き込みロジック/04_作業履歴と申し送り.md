## 設計判断

- `entryWriter` は Firestore の `create()` を使い、ドキュメント ID 重複時に `ALREADY_EXISTS` エラーで冪等制御。`set()` と異なり既存データの上書きリスクがない。
- `monthlyUpdater` は `aggregationMarkers` サブコレクションで二重処理を防止。analytics の既存パターンに合わせた。
- テストは Firestore モックベース（emulator 不要）。モックオブジェクトで `collection/doc/get/set/update/create` を再現。
