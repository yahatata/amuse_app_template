## 変更の概要

`processCashActionAnalyticsAtomically` を呼んでいる箇所の直後に追加する。

```typescript
// 既存（変更しない）
await processCashActionAnalyticsAtomically(db, { ... });

// 追加（新規）
if (!reused && reportingEnabled) {
  const entry = buildCashActionEntry({ billId, cycleNo, cashActionId, ... });
  await writeReportingEntry(db, entry);
  await applyEntryToReportingMonthly(db, entry);

```

transaction 内で取得した `existingAdjustmentsForAllocation` の line 情報を capture して使用する。

## テスト方針

### AI が実行するテスト

| ケース | 確認内容 |

| 後続返金（`cashActionType: "refund"`） | reporting エントリが作成されるか |
