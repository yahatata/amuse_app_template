## `rebuildReportingMonthly` callable の仕様

```typescript
// リクエスト
{ monthKey: string }  // 例: "202605"

// 処理内容
// 1. reportingMonthly/{monthKey} を削除（またはゼロリセット）
// 2. aggregationMarkers を全件削除
// 3. reportingEntries を monthKey でフィルタして全件取得
// 4. 全エントリを reportingMonthly に再集計
// 5. aggregationMarkers を再作成

// 権限: admin のみ
```

**注意:** 再集計中は feature flag を一時的に OFF にするか、書き込みが競合しないよう設計する。  
実装上は「既存の monthly doc を上書き（set）する」アプローチでよい。
