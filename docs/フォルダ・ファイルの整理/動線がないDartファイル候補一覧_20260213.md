## 4. アクティブな動線からの参照がない（to_be_deleted のみから参照）

`to_be_deleted` フォルダ内のファイルからのみ参照されており、アクティブな画面遷移では到達しないウィジェット群です。

| ファイルパス | 参照元 |
|-------------|--------|
| `lib/tournament/active/widgets/display/countdown_display.dart` | `to_be_deleted_tournament_blind_screen.dart` のみ |
| `lib/tournament/active/widgets/display/admin_controls.dart` | `to_be_deleted_tournament_blind_screen.dart`、`to_be_deleted_tournament_runtime_debug_page.dart` |
| `lib/tournament/active/widgets/display/table_grid.dart` | `to_be_deleted_scheduled_tournament_tables_page.dart` のみ |
| `lib/tournament/active/widgets/display/stage_preview_list.dart` | `to_be_deleted_tournament_runtime_debug_page.dart` のみ |
| `lib/tournament/active/widgets/display/waiting_list_view.dart` | `to_be_deleted_scheduled_tournament_waiting_page.dart` のみ |
| `lib/tournament/active/widgets/display/table_seat_cell.dart` | `table_grid.dart`（上記）、`to_be_deleted_scheduled_tournament_table_detail_page.dart` |

※ `table_seat_cell.dart` は `table_grid.dart` から参照されるが、`table_grid` 自体が to_be_deleted のみから参照。
