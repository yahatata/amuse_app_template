## 補足：呼び出しはあるがデプロイ対象外の Functions

以下は**アプリから呼び出しあり**だが、`functions/src/index.ts` で shift モジュールがエクスポートされていないため、現在のデプロイでは含まれていません。リモートの旧デプロイ分が動作している状態です。

- `finalizeDay`, `finalizeMonth`, `calculateInsufficientDays`, `createRecruitments`
- `initBusinessHoursForMonth`, `initShiftDaysForMonth`, `interimConfirmRequests`
- `generateBusinessHoursForMonthFromStyles`, `setBusinessHoursManualForDay`
- `setSufficientOverride`, `sendRecruitmentNotification`, `updateDayAssignments`

これらは**未使用ではない**ため、本一覧には含めていません。デプロイ構成の見直しが必要です。
