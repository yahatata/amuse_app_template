## 1. 位置づけ

`ART-104_外部設定台帳` は外部サービス設定の所在・方式・管理責任の定義台帳である。  
次の内容を管理する:

- どの外部サービスの設定項目が存在するか
- 設定値の保存先（Secret Manager / env / 手動設定 等）
- key 名・パス（実値ではない）
- 設定スコープ（店舗固有 / 中央共通）
- 管理責任者
- 疎通確認の方法の概要

### ART-101 との境界

| ART-101_Config台帳 | ART-104_外部設定台帳 |
|---|---|
| アプリ内の業務設定（config / payrollConfig 等） | 外部サービスとの接続設定（LINE / Secret / IAM 等） |
| Firestore に保存される設定項目 | Secret Manager / env / LINE 管理画面等に設定する項目 |

---

## 2. 管理対象

### 登録する対象

- 店舗側 LINE OA / LIFF / Webhook / Channel Access Token の所在と設定方式
- 中央通知用 LINE / Token の保存先と設定方式
- Secret Manager に保存する key 名とその用途
- IAM / SA の権限配置
- 補助サービス（SendGrid 等）の接続設定の所在

### 登録しないもの（重要）

- **Secret の実値**（絶対に書き込まない）
- **API キーの実値**
- 環境ごとの現在値
- 疎通確認の結果・記録（ART-201 統合ワークブックで担う）

## 4. 主な列の定義

（TSK-104 実施中に Excel 正本と整合した内容へ更新すること）

| 列名 | 意味 | 型 / 候補値 |
|---|---|---|
| 連番 | 行識別子 | 数値 |
| サービス区分 | LINE店舗 / LINE中央 / Secret / IAM / LIFF / Webhook / 補助 | 入力規則 |
| 設定項目名 | 設定の論理名 | 文字列 |
| 保存先 | Secret Manager / env / Firestore / LINE管理画面 / 手動設定 等 | 入力規則 |
| key名・パス | Secret key 名や env 変数名（実値ではない） | 文字列 |
| 設定スコープ | 店舗固有 / 中央共通 / 両方 | 入力規則 |
| 管理責任者 | 設定・更新の責任者 | 文字列 |
| 確認方法 | 疎通確認の方法の概要 | 文字列 |
| 営業開始前必須 | 営業開始前に設定が必須か | TRUE / FALSE |
| 備考 | Token 更新手順・注意事項等 | 文字列 |

---

## 5. 更新時のルール

- Secret の実値を書き込まない（key 名と保存先のみ持つ）
- 疎通確認の記録は書き込まない（ART-201 統合ワークブックで担う）
- 管理責任者が変わった場合は速やかに更新する
- 外部サービスの仕様変更・Account 変更が発生した場合は関連設定項目の更新要否を確認する
