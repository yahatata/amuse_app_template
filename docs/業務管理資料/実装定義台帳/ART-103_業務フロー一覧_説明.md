## 1. 位置づけ

`ART-103_業務フロー一覧` は業務フローの定義正本である。  
次の内容を管理する:

- どの業務フローが存在するか（カテゴリ・名称・FLOW-ID）
- 誰が / どの画面で / 何をするフローか（操作者・画面）
- どの function が起動するか（FN-ID との紐付け）
- 営業開始に必須か・重要度はどの程度か
- フローが完了した状態の定義

確認の実施・記録・判定は ART-201 統合ワークブックが担う。  
本台帳はテスト実行の記録器ではなく定義正本に徹する。

---

## 2. 管理対象

### 登録する対象

- 営業開始スコープに含まれるすべての業務フロー
- 操作者・画面・起動 function が特定できるもの

### 登録しないもの

- テスト観点の詳細（TSK-201 で扱う）
- 確認実行の記録（ART-201 で扱う）
- 将来機能のみのフロー

---

## 3. 行の粒度

1 行 = 1 業務フロー。function の呼び出し単位より粗い業務操作単位で整理する。

例:
- ○ 「シフト提出」（スタッフが画面からシフトを提出する一連の流れ）
- × 「createShiftRequest 呼び出し」（function 単位に細かすぎる）
- × 「スタッフ向け操作全般」（大きすぎる）

---

## 4. 主な列の定義

（TSK-103 実施中に Excel 正本と整合した内容へ更新すること）

| 列名 | 意味 | 型 / 候補値 |
|---|---|---|
| FLOW-ID | フロー識別子（FLOW-xxx） | 文字列 |
| 業務カテゴリ | 会計 / シフト / 予約 / 外部連携 等 | 入力規則（TSK-103 実施時に候補値確定） |
| フロー名称 | フローの短い名称 | 文字列 |
| 操作者 | 管理者 / スタッフ / お客様 等 | 入力規則 |
| 主な画面 | 操作する画面名 | 文字列 |
| 起動function（FN-ID） | 主に呼び出される FN-ID（複数なら `;` 区切り） | 文字列 |
| 営業開始必須 | 営業開始時点で確認が必須か | TRUE / FALSE |
| 重要度 | 高 / 中 / 低 | 入力規則 |
| 完了条件 | フローが正常完了した状態の定義 | 文字列 |
| 確認方法 | 自動テスト / 実機 / AI確認 等の概要 | 入力規則 |
| 備考 | 時期制約・注意事項 | 文字列 |

---

## 5. 更新時のルール

- FLOW-ID は採番後に変更しない（ART-102 の Function-Flow 対応表と整合するため）
- 確認の記録は書き込まない（ART-201 統合ワークブックで担う）
- フローの廃止は行削除ではなく備考に廃止理由を記載する
