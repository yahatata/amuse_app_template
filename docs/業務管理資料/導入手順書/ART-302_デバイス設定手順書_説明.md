> 概要: admin / terminal / table 端末の初期設定・更新・再設定手順を再現可能な形で固定する説明資料
> 主な目的: 端末ごとの設定手順を明文化し、再インストール・アップデート・障害時の手順を担当者が迷わず実施できるようにする
> 正本区分: md正本
> 対象: 導入時に端末設定を担当する担当者、および保守時に端末設定を行う担当者
> 更新区分: 変更時
> 参照元: `docs/残タスク_0623/カテゴリE_導入フロー設計/検討時叩き2.md`; `ART-301_導入チェックリスト_説明.md`
> 参照先: `ART-301_導入チェックリスト_説明.md`

---

## 注意: 本資料は骨格のみ

本資料の具体的な手順内容は、テンプレアプリ検証（TSK-201）完了後および実際の第1回導入を経てから充実させる。  
現時点では骨格（目的・対象端末・構成方針）のみを持つ。

---

## 1. 位置づけ

`ART-302_デバイス設定手順書` は、各端末の初期設定・更新・再設定手順の正本である。

このドキュメントで担うこと:
- admin 端末 / terminal 端末 / table 端末それぞれの初期設定手順
- 再インストール時の手順
- アップデート時の注意点
- 設定後の動作確認方法

このドキュメントで担わないこと:
- LINE / LIFF の設定手順 → ART-303
- config 値の決定 → ART-101
- 外部サービスの認証設定 → ART-104

---

## 2. 対象端末

| 端末種別 | 役割 | 備考 |
|---|---|---|
| admin 端末 | 管理者操作（スタッフ管理・レポート確認等） | — |
| terminal 端末 | POS 操作・受付業務 | — |
| table 端末 | テーブルサービス操作 | ゲームサービス等の場合は別途確認 |

---

## 3. 想定する手順構成（骨格）

（第1回導入後に実際の手順を記載すること）

| フェーズ | 内容 |
|---|---|
| 事前確認 | アプリバージョン・OS バージョンの確認 |
| アプリインストール | 各端末へのアプリ導入 |
| 初期設定 | 端末固有の設定入力（店舗 ID 等） |
| 動作確認 | 基本的な画面遷移・認証の確認 |
| 再インストール手順 | 端末交換・故障時の復旧手順 |
| アップデート手順 | アプリ更新時の確認事項 |

---

## 4. 更新時のルール

- 端末の機種・OS が変わった場合は手順の再確認を行う
- アプリの大きな変更（画面構成変更等）があった場合は手順の更新要否を確認する
- 手順変更時は ART-301 導入チェックリストとの整合を確認する
