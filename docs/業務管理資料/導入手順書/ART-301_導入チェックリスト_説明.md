## 1. 位置づけ

`ART-301_導入チェックリスト` は、新規店舗の導入作業を「どの順で・誰が・何をすれば稼働まで進められるか」を固定する正本である。

このチェックリストで担うこと:
- ゼロから稼働までの導入順序
- 各ステップの担当者・前提条件・完了確認方法
- 他の手順書（ART-302 / ART-303）への参照案内
- 統合ワークブック（ART-201）の実行タイミング

このチェックリストで担わないこと:
- 端末の詳細設定手順 → ART-302
- LINE / LIFF の詳細設定手順 → ART-303
- 既存ユーザーデータ移行 → ART-304（A-6 確定後に整備）
- 確認実行の詳細 → ART-201 統合ワークブック

## 2. 想定する導入順序（骨格）

（TSK-201 完了後・第1回導入後に詳細化すること）

| フェーズ | 内容 | 参照資料 | 担当 |
|---|---|---|---|
| 1. 事前確認 | 前回導入からの変更点・設定差分を確認する | ART-101 / ART-104 | AI補助 + 人 |
| 2. Firebase 環境作成 | Firebase プロジェクトを作成し、初期設定を行う | — | 人 |
| 3. config 設定 | 店舗固有の config 値を Firestore へ投入する | ART-101 | 人 |
| 4. 外部サービス設定 | LINE OA / LIFF / Secret / IAM を設定する | ART-104 / ART-303 | 人 |
| 5. 端末設定 | admin / terminal / table 端末を設定する | ART-302 | 人 |
| 6. 統合ワークブック実行 | 店舗別インスタンスを作成し、確認を実施する | ART-201 | AI + 人 |
| 7. 業務フロー受入確認 | 実際の業務フローを確認して go 判断を出す | ART-201 | 人 |
| 8. 稼働開始 | 導入完了とし、運用を引き渡す | — | 人 |
