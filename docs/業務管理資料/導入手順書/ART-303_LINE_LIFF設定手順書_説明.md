## 1. 位置づけ

`ART-303_LINE_LIFF設定手順書` は、LINE / LIFF に関する導入設定手順の正本である。

ART-104（外部設定台帳）が「何が必要か・どこに保存するか」を定義するのに対し、  
本資料は「どの順で・どの画面で・何を設定するか」の実際の手順を持つ。

このドキュメントで担うこと:
- 顧客向け LIFF / スタッフ向け LIFF の登録手順
- LINE Official Account の作成手順
- リッチメニューの設定手順
- Webhook URL の設定と疎通確認手順
- Channel Access Token の発行・保存手順

このドキュメントで担わないこと:
- Token の実値そのもの（ART-104 で管理。実値は Secret Manager 等）
- 設定項目の所在・管理責任（ART-104）
- 設定後の確認記録（ART-201 統合ワークブック）

## 2. 対象設定範囲

| 設定区分 | 内容 | 備考 |
|---|---|---|
| 店舗側 LINE OA | LINE Official Account の作成・基本設定 | 店舗ごとに作成 |
| 顧客向け LIFF | 顧客が使う LIFF の登録・URL 設定 | — |
| スタッフ向け LIFF | スタッフが使う LIFF の登録・URL 設定 | — |
| リッチメニュー | 顧客向けの LINE メニュー設定 | — |
| Webhook | Webhook URL の設定と疎通確認 | functions の URL を設定 |
| Channel Access Token | Token の発行・Secret Manager への保存 | 実値は Secret Manager に保存 |
| 中央通知用 LINE | amuse-admin 用の LINE 設定 | ART-104 の方針に従う |

## 3. 想定する手順構成（骨格）

（ART-104 確定・第1回導入後に実際の手順を記載すること）

| フェーズ | 内容 |
|---|---|
| LINE OA 作成 | LINE Official Account を作成し基本設定を行う |
| LIFF 登録 | 顧客向け / スタッフ向け LIFF を登録する |
| リッチメニュー設定 | 顧客向けリッチメニューを設定する |
| Webhook 設定 | Webhook URL を設定し疎通確認を行う |
| Token 発行・保存 | Channel Access Token を発行し Secret Manager に保存する |
| 疎通確認 | LINE メッセージ送信・受信が正常に機能するか確認する |

---

## 4. 更新時のルール

- LINE / LIFF の仕様変更（管理画面の変更等）があった場合は手順を再確認する
- Token の保存先変更があった場合は ART-104 との整合を確認する
- Webhook URL が変更になった場合（functions の URL 変更等）は速やかに更新する
