# 中央管理アプリ監視

## 1. このフォルダの目的

中央管理アプリ `amuse-admin` を使って、店舗の

- エラー監視
- Scheduler / Task 監視

をどう運用するかを、保守者向けにまとめる。

---

## 2. まず何を見るか

| 目的 | まず読む資料 |
|------|--------------|
| エラー対応の流れを知りたい | [エラー監視.md](./エラー監視.md) |
| 定期実行の確認方法を知りたい | [Scheduler・Task監視.md](./Scheduler・Task監視.md) |
| 新規店舗を中央監視へ載せたい | [../導入時設定/fireBase紐付け/中央管理アプリ連携手順.md](../導入時設定/fireBase紐付け/中央管理アプリ連携手順.md) |

---

## 3. 監視成立の前提

中央管理アプリで正しく見えるためには、最低限次が必要。

1. 中央 `stores/{storeId}` に店舗が登録されている
2. `enabled=true` である
3. `店舗 Config 同期` が成功している
4. 店舗側から中央 `errorLogs` / `schedulerLogs` / `taskLogs` への書き込みが動いている

この前提が崩れると、画面自体は開けても運用判断ができない。
