# 給与計算に関する通知について（利用者向け）

管理者向けアプリの **管理者ホーム** で、画面上部の **通知（ベルのアイコン）** を押すと、**給与通知** の一覧を開けます。ここに表示される内容は、給与の締め・計算・確定・支払いのタイミングに合わせて届くお知らせです。

本資料では、**いつ・どんな内容の通知が届くか** を説明します。内部の仕組みの名前は使わず、画面上の言い方に寄せています。

---

## 1. 通知一覧の見方

| 画面での操作・表示 | 内容 |
|--------------------|------|
| **給与通知** | 給与関連だけをまとめた一覧です。 |
| フィルター **すべて** | 直近およそ 2 か月分の通知を時刻が新しい順に表示します。 |
| フィルター **未読のみ** | まだ開いていない通知だけに絞ります。 |
| フィルター **フラグ付き** | あとで見返したい通知に印を付けたものだけを表示します。 |
| 1 件タップ | その通知を **既読** にします（背景色が通常に戻ります）。 |
| 長押し | **フラグ** の付け外しができます（星の横に旗マークが付きます）。 |

### 1.1 色とアイコン（重要度の目安）

一覧の左のアイコンと色は、おおよそ次の意味です。

| 見た目のイメージ | 意味の目安 |
|------------------|------------|
| 青系（情報） | お知らせ・報告です。すぐに危険があるとは限りません。 |
| オレンジ系（注意） | 確認や対応をおすすめします。 |
| 赤に近いオレンジ（強い注意） | 支払日が近いなど、優先して確認してください。 |
| 赤（エラー） | 処理に失敗した・一部失敗したなど、確認と対応が必要です。 |

表示される **タイトル** と **本文** に、対象の **期間（いつからいつまでの給与か）** や人数・金額などが入ります。

---

## 2. いつ、どんな通知が届くか

ここでは **「タイトル」** を目印に説明します。本文は期間や人数などが入ります。

### 2.1 給与計算ができる期間に入ったとき

- **タイトル例**: 「給与計算可能期間に入りました」
- **いつ頃**: その給与期間の **最終日の翌日** に、**まだその期間の給与計算を一度も行っていない** とき、**1 回** 届きます。
- **内容の例**: 「○月○日〜○月○日の給与計算が可能です。」のように、期間が書かれます。

### 2.2 そろそろ給与計算をしてほしいとき（繰り返し）

- **タイトル例**: 「給与計算がまだ行われていません」
- **いつ頃**: 給与期間の最終日から、店舗で決めた **「何日後からリマインドを始めるか」**（初期設定では **3 日後**）以降、**まだ計算を実行していない** あいだ、**毎日** 届くことがあります。
- **内容の例**: 対象期間と、**支払予定日**（店舗設定に基づく日付。未設定の場合は本文に「未設定」と出ることがあります）が書かれます。
- **強い注意**に変わるタイミング: **支払予定日の 3 日前**から、同じ内容でも **より強い注意** の表示になることがあります。

### 2.3 計算は終わっているのに、確定がまだのとき（繰り返し）

- **タイトル例**: 「給与確定処理がまだ行われていません」
- **いつ頃**: 上記と同様、期間の最終日から店舗の「リマインド開始日」以降で、**計算は済んでいるが確定していない** とき、**毎日** 届くことがあります。
- **内容の例**: 対象期間について、計算は完了しているが確定処理が残っている、と伝えます。

### 2.4 支払日を過ぎても「支払い済み」の登録が済んでいないとき（繰り返し）

- **タイトル例**: 「支払い済み登録がされていません」
- **いつ頃**: **支払予定日の翌日**から、**給与は確定済みだが、全員分の支払い済み処理が終わっていない** 間、**毎日** 届くことがあります。
- **内容の例**: 対象期間について、支払日を過ぎている、と伝えます。

### 2.5 一部の人だけ支払いを「保留」にしているとき（毎週）

- **タイトル例**: 「保留中の支払いがあります」
- **いつ頃**: **毎週月曜日**に、**保留中の人がいる** ときに届くことがあります。
- **内容の例**: 何人分が保留かが書かれます。

### 2.6 給与計算がすべてうまく終わったとき

- **タイトル例**: 「給与計算が完了しました」
- **いつ頃**: その期間の計算処理が **全員分成功** した直後です。
- **内容の例**: 対象期間、**対象人数**、**総支給額** が書かれます。

### 2.7 給与計算が一部だけ失敗したとき

- **タイトル例**: 「給与計算が一部失敗しました」
- **いつ頃**: 計算処理が終わったが、**一部のスタッフだけ計算に失敗** したときです。
- **内容の例**: 対象期間と、**失敗した人数** が書かれます。結果画面で確認・再実行が必要です。

### 2.8 給与計算全体が失敗したとき

- **タイトル例**: 「給与計算が失敗しました」
- **いつ頃**: その期間の計算が **致命的なエラーで進められなかった** ときです。
- **内容の例**: 対象期間と、再実行してほしい、と伝えます。

### 2.9 すでに給与を確定したあとで、過去の勤怠が直されたとき

- **タイトル例**: 「確定済み期間の勤怠が修正されました」
- **いつ頃**: **確定済みの給与期間**に属する勤怠が、あとから修正されたときです。
- **内容の例**: **どのスタッフの、いつの勤務** が変わったかが書かれます。**確定済みの給与額は自動では更新されない** 旨が伝わる内容です。必要に応じて手動で確認・調整する運用になります。

---

## 3. 通知が届く時間帯について

- 上記のうち、**毎日・毎週のタイミングで出るお知らせ**は、**1 日 1 回**、店舗の **給与・通知まわりの設定で決めた時刻（初期では午前 10 時前後のイメージ）** を目安に判定されます。
- **計算が終わった瞬間**や**勤怠が修正された瞬間**に届くお知らせもあります（その場の操作に近いタイミング）。

※ 実際の表示時刻はサーバー負荷などで多少ずれることがあります。

---

## 4. 利用者への説明で使える一文（例）

- 「給与の締め日が終わった翌日から、管理者ホームの **通知** に、計算や確定、支払いの忘れ防止のお知らせが届きます。」
- 「**給与通知** を開くと、期間ごとに何をすべきかがタイトルと本文で分かります。急ぎのものは色が強く表示されます。」
- 「**確定したあと**に過去の勤怠を直すと、『確定済み期間の勤怠が修正されました』と届きます。金額は自動では変わらないので、必要なら担当者が確認します。」
