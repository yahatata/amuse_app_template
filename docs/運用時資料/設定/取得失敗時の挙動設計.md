# storeMeta/config 取得失敗時の挙動設計

本ドキュメントには、storeMeta/config の**取得失敗時**の挙動を**設定ごと**に記載する。  
※ ID は開発用の識別子のため、本ドキュメントには記載しない。

---

## ケースの切り分け

取得失敗時は、次の 2 ケースを区別する。

| ケース | 内容 | 必須対応 |
|--------|------|----------|
| **読めるがフィールドが存在しない** | ドキュメントは取得できるが、当該設定のフィールドが存在しない | **必ずデフォルト値を適用する** |
| **読めない（Firestore 障害等）** | Firestore の読み取りに失敗した（リトライ後も失敗） | 下記「デフォルト方針」の 2 択から選択 |

---

## デフォルト方針（2 択）

各設定について、取得失敗時のデフォルト挙動は次のいずれかとする。検証時に設定ごとに決定する。

| 方針 | 内容 |
|------|------|
| **A. デフォルトを正とする** | デフォルト値を正としてデフォルトの処理を行う |
| **B. ユーザーに選択させる** | 画面にエラーを表示し、どういう処理かユーザーに選択させる。保守側が検知できるようエラーコードを出す |

---

## 設定ごとの記載

| 設定 | 読めるがフィールド未存在時 | 読めない時（E ケース） |
|------|----------------------------|------------------------|
| **settlementAggregatorEnabled**（決済アグリゲータ有効化） | デフォルト適用（必須。`true`） | A. デフォルトを正とする |
| **dualWriteEnabled**（当日請求デュアルライト有効化） | デフォルト適用（必須。`false`） | A. デフォルトを正とする |
| **payrollStartDay / payrollEndDay**（給与締め日） | デフォルト適用（必須。`26` / `25`） | A. デフォルトを正とする |
| **enqueueSchedulerEnabled**（enqueue スケジューラ有効化） | デフォルト適用（必須。`true`） | A. デフォルトを正とする |
| **templateBusinessDateCheck**（テンプレート営業日重複チェック有効化） | デフォルト適用（必須。`true`） | A. デフォルトを正とする |
| **calcBufferMinutes**（営業日境界バッファ） | デフォルト適用（必須。`70`） | A. デフォルトを正とする |
| **autoOpenClose**（自動開閉店: enabled / taskCloseOffsetMinutes / taskOpenOffsetMinutes） | デフォルト適用（必須。`enabled: true`、`taskCloseOffsetMinutes: 120`、`taskOpenOffsetMinutes: -30`） | A. デフォルトを正とする |
| **businessStyles**（storeMeta/businessStyles: 営業時間スタイル + 必要人数） | doc 未存在時は設定未完了（fallback なし） | B. 設定未完了を UI に表示。Functions は null を返し不足判定をスキップ |
| **linePlan**（LINE プラン種別） | デフォルト適用（必須。`"communication"`） | A. デフォルトを正とする |
| **shift**（submissionStartDay / submissionEndDay / schedulingStartDay） | デフォルト適用（必須。`1` / `15` / `16`） | A. デフォルトを正とする |
| **billing**（entranceFee / entranceFeeDescription / chargeEntranceFeeOnReentry / sideGameChipRate / paymentPolicy） | デフォルト適用（必須。上記すべてデフォルト値） | A. デフォルトを正とする |
| **menuCategories**（メニューカテゴリ） | デフォルト適用（必須。`['フード','ノンアルコール','アルコール','Chip','その他']`） | A. デフォルトを正とする |
| **sideGameTypes**（サイドゲーム種別） | デフォルト適用（必須。`['ブラックジャック','ルーレット','バカラ','アルティメットポーカー']`） | A. デフォルトを正とする |
| **tournament**（トーナメント: defaultPrizeRatio / prizeReceiverPercentage / prizeRoundingMethod / prizeRoundingUnit / prizeDistribution） | デフォルト適用（必須。0.7 / 10 / 'floor' / 100 / 1〜10 人入賞用配分） | A. デフォルトを正とする |
