## 付録C. 調査で新たに見つかった論点（根拠あり）

1. **Flutter Phase 1〜9 は `057f33b` に未収録**（working tree のみ）。実機 Flutter エラー UX は現 tree からのビルドが必要。

4. **勤怠空月:** `ATT_HISTORY_EMPTY_MONTH` は catalog のみ。空月は空白カレンダー。
5. **修正申請:** pending/approved/rejected いずれも同一「すでに申請されています」（rejected 専用 UI なし）。
6. **`getUserOrderHistory` の `businessDate` は shape 必須だが画面未表示。**
7. **`00` §5.3 の unused_function_lib「7件」と `c5b0f63` 削除 10 ファイルは件数不一致**（`00` 未修正）。
8. **SG debug は Terminal 経路 default ON、卓端末 wrap は OFF。**
9. **`joinTournament` は alert の死コード**。`processOrder` は未配線で即 return。`executeWithButtonLoading` は定義のみ。
10. **`_callCreateInitialStateDoc` は Terminal に定義残・呼び出しなし**。正式入口は Admin 詳細設定。
11. **統合ユーザー一覧は `sourcePage: 'StayingUsersListPage'` をキーとして維持**している。画面ファイルは working tree 削除（`c5b0f63` には含まれない）。

14. **Admin シフトはカレンダー/ドラフト/確定/募集まで到達可能**（Terminal グリッドにはない）。
