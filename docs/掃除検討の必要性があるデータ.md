# 掃除検討の必要性があるデータ

## 目的

現時点では保持方針や削除運用を確定しないが、将来的に掃除の必要性を検討すべきデータを記録する。

## 対象データ

### 1. `enqueueTournamentTasksReplanRequests`

- 用途:
  - `enqueueTournamentTasksByScheduler` 向けの再計画要求を一時的に集約する制御用データ
- 現時点の方針:
  - 実装時点では掃除処理を作成しない
  - 保持期間、削除条件、TTL は未確定
- 将来的に検討すべきこと:
  - 実行済み request を残し続ける必要があるか
  - 監査用途と運用用途のどちらを優先するか
  - 最新 1 件保持で十分か、履歴保持が必要か
  - Cloud Logging や専用ログで代替できるか
