## 3. 実装上の判断

- actual reopen runtime は Step02 に含めず Step05 へ送った
- baselineSnapshot の保存先は `baselineSnapshot/snapshot` に固定した
- root snapshot 群は既存互換のため残した
- cycle doc 欠損時は settle 側で on-demand 作成を許容した

## 4. 実装していないもの

- reopen 実行による cycle 進行
- old cycle の closedReason = reopen への更新
- resettle 時の cycle 切替全体

これらは Step05 の主責務である。
