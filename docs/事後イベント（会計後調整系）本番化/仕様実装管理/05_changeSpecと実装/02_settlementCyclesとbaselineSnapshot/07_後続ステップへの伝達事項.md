# 07_後続ステップへの伝達事項

## 1. Step03 / Step04 への伝達

- `settlementCycles/{cycleNo}` は current-scope で作成済みである
- `nextSequenceNo` 初期値は `1` であり、後続の adjustment / cashAction 採番起点として利用する
- baseline の保存先は `bills/{billId}/settlementCycles/{cycleNo}/baselineSnapshot/snapshot` で固定する

## 2. Step05 への伝達

- actual reopen runtime は未実装である
- Step05 では少なくとも次を実装する必要がある
  - old cycle の close
  - new cycle の open
  - `currentSettlementCycle` 進行
  - `openedReason = reopen`
  - `openedFromCycleNo` の設定
- Step02 では create / settle パスだけを保証している

## 3. Step07 への伝達

- `baselineSummary` は cycle 親 doc に保存済みである
- `baselineSnapshot/snapshot` には analytics 再構成に必要な items / extras / tournaments / sideGameChips の最小 shape が入る
- root snapshot 群も当面は残るため、移行時は参照優先順位に注意する

## 4. 共通注意

- current-scope では migration / backfill を行っていない
- 欠損 cycle doc は settle 時に on-demand 作成されるが、後続 step では create path 前提の存在を基本とする
