## 3. Step05 で意図的に扱っていないもの

- 旧 `postEventReopen` callable / `billsEventsOnCreate` trigger の改修・廃止 → Step06 主責務
- UI 切替（旧 callable から新 callable への差替え） → Step06 主責務
- `analyticsMonthly` の rollback / resettle 反映 → Step07 主責務
- 当日以外の bill の reopen（current-scope 外、上流で禁止）
- `closeSummary` / `requireSpecialAttention` 等の補助 field の reset（仕様書記述外）
- migration / backfill（未リリース前提）

これらは仕様書 §3 と Step04 handoff の境界に従い、Step05 完了条件には含めない。
