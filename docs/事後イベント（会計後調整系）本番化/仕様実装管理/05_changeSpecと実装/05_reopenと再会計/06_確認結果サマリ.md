## 6. テスト失敗時の再起動ルール

- 今回は Emulator 依存テストの失敗なし
- 一度だけ「`storeMeta が running でないとき失敗`」のシナリオで firebase-admin SDK の Firestore singleton と test 側 `db = getFirestore()` の同期問題により reopen が成功してしまうケースが発生
  - 当該テストは storeMeta module 側の unit テストでカバー済みのため、reopen の practical な不一致シナリオを `当日と異なる businessDate` テストに集約し、不安定要因を排除
  - 詳細は [05_実装サマリ.md §7.1](/Users/yahatayuusei/Documents/GitHub/amuse_app_template/docs/事後イベント（会計後調整系）本番化/仕様実装管理/05_changeSpecと実装/05_reopenと再会計/05_実装サマリ.md) に記録
