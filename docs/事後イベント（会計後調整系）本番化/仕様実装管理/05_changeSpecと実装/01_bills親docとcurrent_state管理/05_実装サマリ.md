## 2. 実装概要

- `functions/src/domains/bills/services/parentSummary.ts` を追加し、parent target contract 用の初期値 / snapshot / summary 生成 helper を導入した
- bill 作成時に `ops`, `draftAccountingInput`, `settlementSnapshot`, `currentSummary`, `postSettlementState`, `reopenSummary`, `closeSummary` の初期値を親 doc に書くようにした
- 会計開始時に `draftAccountingInput.*` を `meta.*` と並行して更新するようにした
- 会計取消時に `ops.accountingStarted*` を delete ではなく `null` に戻し、target contract に寄せた
- settle trigger で `settlementSnapshot`, `currentSummary`, `postSettlementState`, `reopenSummary.lastResettledAt`, `draftAccountingInput` を更新するようにした
- close 処理で `closeSummary` を新設し、`closeSnapshot` と並行して unresolved 管理するようにした
- `updateBill` で parent summary 群の直接更新を禁止した
- `createBillWithActiveStay` の repo error contract を他 helper と揃え、`FunctionCustomError` を `HttpsError` へ map するようにした
