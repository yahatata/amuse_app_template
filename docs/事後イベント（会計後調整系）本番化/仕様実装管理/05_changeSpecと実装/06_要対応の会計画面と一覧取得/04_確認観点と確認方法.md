### 2.4 dialog widget test

ファイル: `test/Accounting/postSettlementCollectionDialogTest.dart` / `test/Accounting/postSettlementRefundDialogTest.dart`

| 観点 | 検証 |
|---|---|
| 初期表示 | `requiredActionIncl` が初期 amount に入る |
| 入力欄: amount | 数値入力可能 |
| 入力欄: methodBreakdown | 1 method の入力欄あり |
| 「徴収する」(or 「返金する」) ボタン | callable 呼び出しが mock で発火、引数が正しい |
| callable 成功時 | dialog 閉じる + SnackBar 表示 |
| callable 失敗時 (failed-precondition) | dialog 閉じない + エラー SnackBar / Dialog |
| キャンセルボタン | callable は呼ばれず dialog 閉じる |
| ローディング中 | ボタンが disabled、CPI 表示（`flutter-loading-display.mdc` 準拠） |
