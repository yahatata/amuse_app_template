| 数値入力欄 / methodBreakdown の入力 | dialog widget の build ツリーで `TextField(keyboardType: TextInputType.number)` / `DropdownButtonFormField<String>` を構築 | 達成 |
| 「徴収する」/「返金する」ボタン | コードレベルで `_submit` ハンドラ + `_functions.httpsCallable('recordPostSettlement(Collection|Refund)').call(payload)` 呼び出しを確認 | 達成 |

| 成功時 dialog 閉じ + SnackBar | `Navigator.of(context).pop()` + `ScaffoldMessenger.of(context).showSnackBar(...)` をコードで確認 | 達成 |

| キャンセルボタン | `TextButton(onPressed: _submitting ? null : () => Navigator.of(context).pop(), child: Text('キャンセル'))` を確認 | 達成 |
