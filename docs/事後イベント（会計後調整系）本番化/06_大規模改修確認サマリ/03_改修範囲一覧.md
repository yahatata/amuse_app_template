├─ baselineSnapshot/snapshot

- adjustment marker: `adj_{adjustmentId}`

- reopen marker: `reopen_{billId}_cycle{oldCycleNo}`

## 6. セキュリティルール

今回の current-scope での整理は次のとおり。

- `firestore.rules`
  - 新 UI / 新 subcollection read path は既存の開発用 read 許可で到達可能
  - 本番向け read 制限の再設計は別フェーズ
- `firestore.indexes.json`
  - `要対応の会計` 画面で使う `bills` 複合条件 query 用 composite index を追加
  - `firestore:indexes,firestore:rules` を deploy 済み

補足:

- deploy 時に、プロジェクト側にだけ存在する index が 6 本あると表示された
- 既存経路を壊さないため、今回は `--force` を使わず温存している
