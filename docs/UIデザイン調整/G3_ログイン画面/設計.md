# G3: ログイン・アカウント画面 設計

最終更新: 2026-09-10

---

## なぜ（背景・目的）

- `userCheckInPage`（QR/手動 2択）は縦並びの細いボタンがタブレットの横幅を持て余しており、操作感・見た目ともに貧弱
- `UserManualCheckInPage`（手動チェックインフォーム）は幅制限がなく iPad で横いっぱいに広がる
- `createUserAccountPage`（新規アカウント作成）はラベルが英語で、幅制限もなく横に広がる
- `shiftMenuPage` / `businessDayMenuPage` は G2 で overflow は解消したが `Expanded` のままで各ボタンが画面の 50% を占め、トーナメント作成メニュー（基準デザイン）のボタン高さ 25% と乖離している

---

## 完了の定義

- G3-03: userCheckInPage のボタンが横並び（3:4比率・色付きカード）になり画面中央に表示される
- G3-02: UserManualCheckInPage のフォームが最大幅 400pt で中央配置される
- G3-01: createUserAccountPage のラベルが日本語化され、カード型・最大幅 480pt で中央配置される
- G3-04/05: シフトメニュー・営業日メニューのボタン高さがトーナメント作成メニューと同じになる（画面の約 1/4）
- すべて Redmi・iPad Air で overflow せず表示される

---

## G3-04 / G3-05: シフトメニュー・営業日メニュー（ボタン高さ統一）

### 対象ファイル
- `lib/StaffDate/shiftMenuPage.dart`
- `lib/StaffDate/businessDayMenuPage.dart`

### 基準となるデザイン
`tournament_creation_menu_page.dart` が基準:
```
SafeArea > Padding(all:24) > Column > [Expanded × 4 + SizedBox(16) × 3]
```
各ボタン高さ ≈ `(body_h - 24×2 - 16×3) / 4 = (body_h - 96) / 4`

### 変更内容
- `body` を `SafeArea > LayoutBuilder > Padding(all:24) > Column` に変更
- `Expanded` → `SizedBox(height: btnH)` に変更
  - `btnH = (constraints.maxHeight - 48 - 48) / 4`
    - 第1の 48 = top padding 24 + bottom padding 24
    - 第2の 48 = gap 16 × 3（トーナメント作成ページに合わせる）
- ボタン間の `SizedBox(height: 16)` はそのまま維持
- ボタンより下の残り空間は自然な余白（ボタンを上に詰める）
- `SafeArea` 追加（现状は未付与）

### ボタンのスタイル（変更なし）
```dart
ElevatedButton.styleFrom(
  backgroundColor: Colors.grey[100],
  foregroundColor: Colors.grey[800],
  elevation: 2,
  shape: RoundedRectangleBorder(
    borderRadius: BorderRadius.circular(8),
    side: BorderSide(color: Colors.grey[300]!, width: 1),
  ),
),
```

## G3-03: userCheckInPage（QR/手動 2択 横並びカード）

### 対象ファイル
- `lib/UserLogin/userCheckInPage.dart`

### レイアウト

```
┌────────────────────────────────────────────┐
│               AppBar                        │
│                                            │
│                                            │
│        ┌──────────┐  ┌──────────┐          │
│        │  📷(52)  │  │  ✏️(52) │          │
│        │          │  │          │          │
│        │QRチェック │  │ 手動チェック│         │
│        │ イン     │  │ イン     │          │
│        └──────────┘  └──────────┘          │
│           GREEN         AMBER              │
│                                            │
└────────────────────────────────────────────┘
```

### サイズ計算（LayoutBuilder 使用）
```
availW = constraints.maxWidth
availH = constraints.maxHeight
gap = 32.0
hPadding = 48.0  // 左右の余白（中央配置のため Row mainAxisSize: min を使用）
btnW = min(240.0, (availW - hPadding * 2 - gap) / 2)
btnH = min(btnW * 4 / 3, availH * 0.65)
```

### ボタンデザイン

| 項目 | QRチェックイン | 手動チェックイン |
|-----|-------------|--------------|
| 背景色 | `Colors.green[50]` | `Colors.amber[50]` |
| 前景色（アイコン・テキスト） | `Colors.green[800]` | `Colors.amber[800]` |
| ボーダー色 | `Colors.green[200]` | `Colors.amber[200]` |
| アイコン | `Icons.qr_code_scanner` | `Icons.edit` |
| 角丸半径 | 20pt | 20pt |
| アイコンサイズ | 52pt | 52pt |
| ラベルフォント | 16pt / FontWeight.w600 | 同左 |
| アイコン〜ラベル間隔 | 12pt | 12pt |

### 実装方針
- 現在の `body: Center > Padding > Column > [ElevatedButton.icon × 2]` を全面置き換え
- `body: LayoutBuilder > Center > Row(mainAxisSize: min) > [_CheckInCard × 2]`
- `_CheckInCard` は `StatelessWidget` として抽出
- `Material + InkWell` ベースで実装（`ElevatedButton` では角丸・色の自由度が低いため）
- `_openQRCheckIn()` / `_openManualCheckIn()` のロジックは変更なし

## G3-02: UserManualCheckInPage（フォーム幅制限・アイコン縮小）

### 対象ファイル
- `lib/UserLogin/UserManualCheckInPage.dart`

### 変更内容
- `Icon(Icons.lock, size: 80)` → `size: 48` に縮小
- フォーム全体を `Center > ConstrainedBox(maxWidth: 400)` で囲む
- ログインボタン: `SizedBox(width: double.infinity)` でカード内いっぱい
- ロジック・バリデーション・エラーダイアログは変更なし

### 変更後のbodyイメージ
```dart
body: Padding(
  padding: const EdgeInsets.all(16.0),
  child: Center(
    child: SingleChildScrollView(
      child: ConstrainedBox(
        constraints: const BoxConstraints(maxWidth: 400),
        child: Form(
          key: _formKey,
          child: Column(
            children: [
              Icon(Icons.lock, size: 48, color: Colors.blue),
              ...
              SizedBox(
                width: double.infinity,
                child: ElevatedButton(child: Text('ログイン')),
              ),
              ...
            ],
          ),
        ),
      ),
    ),
  ),
),
```
