## G3-A: ユーザーログイン（2択メニュー）

**確認内容:**

1. ✅ / ❌ QRチェックインと手動チェックインの**2つのボタンが横並び**になっている（縦並びではない）
2. ✅ / ❌ ボタンが**画面中央**に配置されている
3. ✅ / ❌ QRチェックインボタンが**緑色系**（薄い緑背景・濃い緑テキスト）になっている
4. ✅ / ❌ 手動チェックインボタンが**黄色（アンバー）系**になっている
5. ✅ / ❌ ボタンが縦長（縦横比がおおよそ 3:4 = 横より縦が長い）になっている
6. ✅ / ❌ ボタンの角が丸くなっている
7. ✅ / ❌ QRチェックインをタップするとQR読み取り画面に遷移する（既存動作）
8. ✅ / ❌ 手動チェックインをタップすると手動チェックイン画面に遷移する（既存動作）
9. ✅ / ❌ overflow が発生していない

## G3-B: 手動チェックイン（フォーム画面）

**確認内容:**

1. ✅ / ❌ フォームが**画面横いっぱいに広がらず**、中央に収まっている（特にiPadで確認）
2. ✅ / ❌ ロックアイコンが画面上部にある（以前より小さくなっている）
3. ✅ / ❌ ログインボタンが**フォームの幅いっぱい**に広がっている
4. ✅ / ❌ 各フィールドの**ラベルが入力BOX内ではなく上側に固定表示**されている

5. ✅ / ❌ ログインIDの入力BOX内に `ポーカーネーム+誕生日（MMDD）※スペース等なし` が薄く表示されており**途切れずに表示**されている（入力前のみ）
6. ✅ / ❌ PINの入力BOX内に `4桁の数字` が薄く表示されている（入力前のみ）
7. ✅ / ❌ 「新規登録はこちら」リンクが表示されている
8. ✅ / ❌ overflow が発生していない

## G3-C: 新規アカウント作成

**確認内容:**

1. ✅ / ❌ フォームが**カード（Card）の中**に収まっている（白い背景の箱で囲まれている）
2. ✅ / ❌ カードが**画面横いっぱいに広がらず**、中央に収まっている（特にiPadで確認）
3. ✅ / ❌ カードの上部に「新規アカウント作成」というタイトルが表示されている
4. ✅ / ❌ 各フィールドの**ラベルが入力BOX内ではなく左側に固定表示**されている
   - 「ポーカーネーム」が入力BOX左に表示（旧: PokerName がBOX内ラベル）
   - 「メールアドレス」が入力BOX左に表示（旧: MailAddress）
   - 「PIN（4桁）」が入力BOX左に表示（旧: PIN (4桁数字)）
   - 「生年月日（MM/DD）」が入力BOX左に表示（旧: BirthDay (MMDD)）
5. ✅ / ❌ 各入力BOX内にヒントテキスト（薄い文字）が表示されている（入力前のみ）
   - ポーカーネーム: `（例）yamaTaro`
   - メールアドレス: `（例）example@mail.com`
   - PIN（4桁）: `4桁の数字`
   - 生年月日（MM/DD）: `（例）1月1日→0101`
6. ✅ / ❌ 「新規登録」ボタンがカードの幅いっぱいに表示されている
7. ✅ / ❌ overflow が発生していない
8. ✅ / ❌ フォーム入力・送信の動作が問題ない（既存動作）
