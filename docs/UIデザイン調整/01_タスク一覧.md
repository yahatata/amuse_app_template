### PRE-01 DeviceOption検証チートシート

以下のすべてのオプションキーについて、「このキーのみ設定した端末」で対応ボタンがアクティブになり、他がグレーになることを確認する:

| DeviceOptionKey | アクティブになるべきボタン |
|----------------|----------------------|
| `order` | 注文画面 |
| `kitchen` | 注文管理 |
| `userEntryExit` | ユーザーログイン |
| `staffEntryExit` | 勤怠打刻 |
| `accounting` | 会計管理・要対応の会計・会計後操作（3つ同時） |
| `tournament` | Tournament作成・Tournament Home・卓ページ・ブラインドタイマー（4つ同時） |
| `tournamentTable` | 卓ページのみ（Tournament系3ボタンはグレーのまま） |
| `sideGame` | サイドゲーム |
| `storeManagement` | 営業管理（ダイアログ起動） |

`optionKeys=null` → 常にアクティブ: **メニュー追加・ユーザー作成・入店中ユーザー一覧**
