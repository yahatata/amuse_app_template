# G4: Terminal モードバナー 確認手順

## 確認に必要なもの

- **Admin 権限（role = admin）のデバイス**で動作させたアプリ
- サブページへ移動するための操作（Terminal モード内のどのボタンでも可）

---

## 確認項目

### ① Admin モード時：バナーが表示されないこと

1. アプリを起動し、Admin ホーム（Admin モード）を表示する
2. 画面の一番上にティール色のバナーが**表示されていないこと**を確認

---

### ② Terminal モードに切り替える：バナーが表示されること

1. Admin ホームの AppBar 右にある「Adminモード中」ボタンをタップ
2. Terminal ホームに切り替わり、画面の一番上に以下のバナーが表示されることを確認：
   - 色：ティール（緑がかった青）
   - 左テキスト：`AdminデバイスTerminalモード中`
   - 右ボタン：`Terminalモード中`（白背景・ティール文字）

---

### ③ HOME 画面でのボタン有効確認

1. Terminal モード中、バナー右の「Terminalモード中」ボタンをタップ
2. Admin モードに切り替わり、バナーが消えること
3. もう一度「Adminモード中」ボタンをタップして Terminal モードに戻す

---

### ④ サブページでボタンが無効になること

1. Terminal モードのまま、Terminal ホームのいずれかのボタン（例：ユーザー作成 等）をタップしてサブページに移動
2. サブページの一番上にバナーが引き続き表示されていること
3. バナー右のボタンが**グレー表示**に変わっていること
4. グレーのボタンをタップすると、画面遷移せず以下のダイアログが表示されること：
   > 「モード切り替えできません」
   > HOME画面からしかモード切り替えできません。
   > HOMEに戻ってから切り替えボタンを押してください。
5. 「OK」をタップするとダイアログが閉じ、サブページのまま留まること

---

### ⑤ HOME に戻るとボタンが有効に戻ること

1. サブページからデバイスの「戻る」またはアプリ内のナビゲーションで Terminal ホームに戻る
2. バナー右のボタンが**白背景・ティール文字**に戻っていること
3. タップすると Admin モードに切り替わりバナーが消えること

---

### ⑥ admin 以外のデバイスではバナーが表示されないこと（可能であれば）

1. role が `terminal` のデバイスでアプリを起動
2. Terminal ホームが表示されるが、バナーが**一切表示されないこと**を確認

---

## 確認完了後

上記①〜⑤（⑥は任意）がすべて問題なければ G4 完了です。
確認結果を Cursor に共有してください。
