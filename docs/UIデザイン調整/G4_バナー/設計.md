# G4: Terminal モードバナー 設計

## なぜこれが必要か

Admin 端末を Terminal モードで使うと、見た目が普通の Terminal 端末と同じになる。
スタッフが「今この端末は Admin 権限のある特別な状態で動いている」と認識できないまま操作してしまうリスクを防ぐため、
画面の一番上に常時バナーを表示する。

## バナーの仕様

| 項目 | 値 |
|---|---|
| 表示条件 | role = admin のデバイス かつ Terminal モード中のみ |
| 高さ | 48px（ステータスバー領域は別途確保） |
| 背景色 | ティール `#00796B`（案A） |
| 文字色 | 白 |
| 左テキスト | `AdminデバイスTerminalモード中` |
| 右ボタン | モード切り替えボタン（HOME 画面 = 有効、サブページ = グレーアウト） |
| バナー本体タップ | 何も起きない |

---

## モード切り替えボタンの挙動

### HOME 画面にいるとき（有効）

- ボタン色：白背景・ティール文字
- タップ：Terminal モード → Admin モードに切り替え（バナーが消える）

### サブページにいるとき（無効）

- ボタン色：グレー
- タップ：画面遷移なし。以下のダイアログを表示するだけ

> 「モード切り替えできません」
> HOME画面からしかモード切り替えできません。
> HOMEに戻ってから切り替えボタンを押してください。

## 技術設計

### 状態管理（ValueNotifier）

グローバルな `ValueNotifier` を 2 つ用意し、プロセス間の橋渡しに使う。
Provider や Riverpod などのパッケージは使用しない（既存コードへの影響を最小化）。

```
terminalModeNotifier     : bool  Terminal モード中かどうか
isOnHomeScreenNotifier   : bool  AdminHomePage が最前面かどうか
```

### バナーの挿入位置

`MaterialApp.builder` を使い、Navigator の上にバナーを配置する。
この方法により、サブページを含む全ルートでバナーが表示される。

```
MaterialApp
  └─ builder
       ├─ ColoredBox (teal) + SizedBox(statusBarHeight) ← ステータスバー塗りつぶし
       ├─ TerminalModeBanner (48px)
       └─ Expanded > MediaQuery(top:0) > child (Navigator)
```

`MediaQuery.padding.top` を 0 にすることで、子 Scaffold の AppBar がバナーと重複しないようにしている。

### HOME判定（RouteAware）

`AdminHomePage` が `RouteAware` を mixin し、`appRouteObserver`（MaterialApp に登録済み）を購読。

- `didPushNext()` → `isOnHomeScreenNotifier.value = false`（サブページへ遷移）
- `didPopNext()` → `isOnHomeScreenNotifier.value = true`（サブページから戻る）

### Admin モード時の AppBar

Terminal モード中はバナーに切り替えボタンが移動するため、AppBar には表示しない。
Admin モード時のみ AppBar に「Adminモード中」ボタンを表示（従来と同じ）。

---

## admin 権限チェックについて

バナーの表示条件は `terminalModeNotifier.value == true` のみ。
`terminalModeNotifier` は `AdminHomePage` の `initState` でのみ `true` に設定される。
`AdminHomePage` へのルーティングは `device.role == 'admin'` のときのみ（`main.dart` / `app_home_navigation.dart`）。
→ 結果として、admin role のデバイスでのみバナーが表示される。
