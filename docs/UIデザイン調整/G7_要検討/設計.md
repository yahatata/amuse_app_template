## G7-03: ホーム画面ボタンの縦比率問題を修正

### 問題

iPad Air（大画面）でホーム画面を表示すると、ボタンが画面の高さを使い切れず、上下に大きな余白が生まれていた。  
Redmi（Android）と比べて、ボタンが画面に占める割合が小さく見えた。

**根本原因:** `lib/theme/home_button_theme.dart` の `calcAdminBtnH` 関数内で、ボタン高さが「ボタン幅と同じ（正方形）」を上限としていた。

```dart
// 修正前：正方形が上限
final btnH = rawH.clamp(48.0, btnW);
```

iPad Air では幅が広いため `btnW` が大きくなる（例：220pt）。しかし、ボタン2行分で使える縦スペースはそれ以上あるため（例：680pt）、正方形制約のせいで 440pt しか使えず、残り約 240pt が上下余白に分配されてしまっていた。

### 修正内容

**ファイル:** `lib/theme/home_button_theme.dart`

```dart
// 修正後：幅の1.3倍まで許容（縦にもう少し伸びる）
final btnH = rawH.clamp(48.0, btnW * 1.3);
```

`1.3` という値は「正方形より少し縦長になる程度」のデザイン判断値。幅より大きくなるため縦に空きが出にくくなる。

### 対象範囲

`calcAdminBtnH` のみ変更（Admin ホームの2行レイアウト用）。  
Terminal ホームの `calcTerminalBtnH` は上限なし（`double.infinity`）のため修正不要。

## G7-02: PIN 入力欄に表示/非表示トグルを追加

### 問題

`createUserAccountPage.dart`（新規アカウント作成ページ）の PIN 入力欄は常に `●●●●` で隠れたままで、入力内容を確認する手段がなかった。

### 修正内容

**ファイル:** `lib/UserRegisterView/createUserAccountPage.dart`

1. `_obscurePin` 状態変数を追加（初期値 `true` = 隠す）
2. `_buildTextField` メソッドに `obscure` / `onToggleObscure` パラメータを追加
3. PIN フィールドに `suffixIcon` として `Icons.visibility` / `Icons.visibility_off` のアイコンボタンを追加
4. タップするたびに `_obscurePin` が反転し、表示/非表示が切り替わる

```dart
// 状態変数（State クラスに追加）
bool _obscurePin = true;

// フィールド呼び出し側（変更）
_buildTextField(
  _pinController, "PIN（4桁）", Icons.lock,
  isPin: true,
  obscure: _obscurePin,
  onToggleObscure: () => setState(() => _obscurePin = !_obscurePin),
)
```

## G7-05: SnackBar 色ルール統一

### 問題

SnackBar の表示色が画面ごとにバラバラだった。特に：
- 警告用に `Colors.orange` を使っているファイルが存在した（本来は `Colors.amber` が黄色に近い）
- 成功・エラー・バリデーションメッセージの色が未設定（グレー）のまま混在していた

### 確定したルール

| 種別 | 色 | 代表的な使用例 |
|---|---|---|
| 成功・完了 | `Colors.green` | 登録完了・更新完了・作成完了 |
| エラー | `Colors.red` | 通信エラー・データ取得失敗・処理失敗 |
| 警告（入力不備・制約） | `Colors.amber` | 未入力・形式エラー・制約違反 |
| お知らせ・情報 | 色なし（グレー/デフォルト） | 一般的な操作フィードバック |

### 修正内容

**修正ファイル一覧:**

| ファイル | 主な変更 |
|---|---|
| `lib/StaffDate/shift_style_required_staff_settings_page.dart` | `Colors.orange` → `Colors.amber`（警告の正しい色に修正） |
| `lib/Home/staffDetailPage.dart` | 入力バリデーション→amber、成功→green |
| `lib/Home/staffRetirementPage.dart` | エラー系→red |
| `lib/UserRegisterView/createUserAccountPage.dart` | アカウント作成成功→green |
| `lib/tournament/scheduling/pages/create_single_tournament_page.dart` | バリデーション→amber、成功→green、エラー→red |
| `lib/tournament/scheduling/pages/create_tournament_from_calendar_page.dart` | バリデーション→amber、成功→green |
| `lib/tournament/scheduling/recurring/create_recurring_tournament_page.dart` | バリデーション→amber、成功→green |
| `lib/tournament/scheduling/recurring/edit_recurring_tournament_page.dart` | 更新成功→green |
| `lib/tournament/scheduling/recurring/recurring_tournament_list_page.dart` | 削除成功→green |
| `lib/Accounting/accountingPage.dart` | 成功→green、制約違反→amber、失敗→red |
| `lib/Home/terminalHomePage.dart` | 解消通知→green、取得失敗→red |

**スコープ外（未変更）:**  
会計内部ページ・ユーザーアクションポップアップ・その他サブページの SnackBar は色なし（グレー）のまま。  
これらは「お知らせ扱い（グレー統一）」として定義し、将来の追加時にルールに従うことで対応する。
