## G7-03: ホーム画面ボタンの縦比率

**確認デバイス:** iPad Air（修正対象）

**操作:**
1. Admin ホーム（Adminモード）を開く

**確認ポイント:**
- ボタンが画面の上下を以前より多く使っていること（正方形より少し縦長になっている）
- 上下の余白が以前より小さくなっていること
- ボタンのサイズが極端に変わりすぎていないこと（横より 1.3 倍以内の縦長）
- ボタン内のアイコンとテキストが正しく表示されていること（見切れ・重なりなし）

> ⚠️ 比率の調整値（1.3）は仮の値です。大きすぎる・小さすぎると感じた場合は報告してください。

## G7-02: PIN 表示/非表示トグル

**確認デバイス:** どのデバイスでも確認可

**操作:**
1. 新規アカウント作成ページを開く
2. PIN（4桁）入力欄の右端に目のアイコンが表示されていることを確認
3. アイコンをタップする → PIN が表示されること（`●●●●` → 数字）
4. もう一度タップする → 再び非表示になること（数字 → `●●●●`）
5. PIN を入力した状態でトグルしても文字が正しく切り替わること

## G7-05: SnackBar 色ルール

**確認デバイス:** どのデバイスでも確認可

以下の操作でそれぞれ SnackBar の色を確認してください。

### 成功（緑）
| 操作 | 期待する色 |
|---|---|
| 新規アカウント作成を完了する | 🟢 緑 |
| 銀行口座情報を更新する（スタッフ詳細） | 🟢 緑 |
| 退職手続きを完了する | 🟢 緑 |
| トーナメントを作成する | 🟢 緑 |
| 定期開催トーナメントを作成する | 🟢 緑 |
| 開始時刻を更新する | 🟢 緑 |
| 定期開催を削除する | 🟢 緑 |
| 会計を完了する | 🟢 緑 |

### 警告・バリデーション（黄色/amber）
| 操作 | 期待する色 |
|---|---|
| 時給を未入力のまま更新ボタンを押す | 🟡 黄 |
| トーナメント作成でテンプレートを選ばずに進む | 🟡 黄 |
| 時刻を不正な形式で入力する | 🟡 黄 |
| 決済方法を選ばずに会計を進める | 🟡 黄 |

### エラー（赤）
| 操作 | 期待する色 |
|---|---|
| 退職手続きでエラーが発生した場合 | 🔴 赤 |
| トーナメント作成でサーバーエラーが発生した場合 | 🔴 赤 |

> ℹ️ エラーは意図的に発生させるのが難しいため、確認できる範囲で構いません。
