## 確認対象ページへのアクセス方法

```
Admin ホーム
  ├─ 「シフト」ボタン → シフトメニュー画面      ← G2-01
```

## G2-01: シフトメニュー画面（shiftMenuPage）

| 確認項目 | 期待値 | OK/NG |
|---------|-------|-------|
| 黒黄の斜線・「BOTTOM OVERFLOWED」が**消えている**か | エラーなし | |
| 「シフトカレンダー」ボタンが画面上半分に表示されているか | 上半分に大きく表示 | |
| 「シフトドラフト」ボタンが画面下半分に表示されているか | 下半分に大きく表示 | |
| 2つのボタンが均等な高さで並んでいるか | ほぼ同じ高さ | |
| ボタンをタップして正しく遷移するか | 各ページへ遷移 | |
| iPad Air 11" でも正常に表示されるか（確認できれば） | overflow なし | |
