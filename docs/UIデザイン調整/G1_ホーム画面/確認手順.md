# G1 確認手順（人間担当）

作成日: 2026-09-10
確認端末: iPad Air 11" / Redmi Pad SE 11" / Philips T8015（横向き固定）

---

## 事前準備

1. `flutter run` でアプリを起動する
2. 以下の2パターンで確認する
   - **Terminalデバイス（全オプション設定済み）**
   - **Adminデバイス（AdminモードとTerminalモードを切り替えて確認）**

---

## T-1: Terminal ホーム（全オプション有効端末）

### T-1-01: レイアウト確認（視覚）

| 確認項目 | 期待値 | OK/NG |
|---------|-------|-------|
| 3行ペアが表示されているか | Row1=営業+ユーザー / Row2=会計+注文 / Row3=Tournament+SideGame | |
| 全16ボタン（+営業管理＝計16）が色付きで表示されているか | グレーのボタンが0個 | |
| 各カテゴリに色・アイコン・ラベルが表示されているか | カテゴリヘッダー（左バー+テキスト）も見えること | |
| ボタンにグレー枠線があるか | 薄いグレーボーダーが確認できること | |
| スクロールなしで全ボタンが1画面に収まっているか | スクロールしなくても全行が見えること | |
| Overflow エラーが出ていないか | 赤いOverflowバナーが表示されないこと | |

### T-1-02: タップ確認（操作）

以下の各ボタンをタップして正しい画面に遷移するか確認する:

| ボタン | 期待動作 |
|-------|---------|
| ユーザーログイン | チェックインページに遷移（Row1左：ユーザー内1番目） |
| ユーザー作成 | ユーザー作成ページに遷移（Row1左：ユーザー内2番目） |
| 入店中ユーザー一覧 | ユーザー一覧ページに遷移（Row1左：ユーザー内3番目） |
| 営業管理 | ダイアログが開く（Row1右：営業内1番目） |
| 勤怠打刻 | スタッフ勤怠ページに遷移（Row1右：営業内2番目） |
| メニュー追加 | メニューエディタページに遷移（Row1右：営業内3番目） |
| 会計管理 | 会計ページに遷移 |
| 要対応の会計 | 要対応会計ページに遷移 |
| 会計後操作 | 会計後操作ページに遷移 |
| 注文画面 | 注文カテゴリ選択ページに遷移 |
| 注文管理 | 注文管理ページに遷移 |
| Tournament作成 | Tournament作成メニューページに遷移 |

## T-2: Terminal ホーム（オプション限定端末）

### 対象: 会計オプションのみ付与された端末で確認

| 確認項目 | 期待値 | OK/NG |
|---------|-------|-------|
| 会計カテゴリ3ボタンが色付きで表示されるか | 通常スタイル（色あり） | |
| Tournament / SideGame ボタンがグレーアウトされているか | グレー背景・グレーテキスト | |
| グレーアウトボタンをタップしても何も起きないか | 遷移なし・ダイアログなし | |
| `optionKeys=null` ボタン（ユーザー作成、入店中一覧、メニュー追加）が色付きか | 通常スタイル | |
| 営業管理がグレーアウトされているか（storeManagement未設定） | グレー | |
