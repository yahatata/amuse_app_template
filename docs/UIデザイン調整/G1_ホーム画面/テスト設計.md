## UT-02: home_layout_calc_test.dart

### UT-02-01: Terminal btnW 計算
```dart
// availW=1000 のとき
// btnW = (1000 - 28 - 40 - 22) / 6 = 910/6 ≈ 151.67
expect(calcBtnW(1000, numSlots: 6), closeTo(151.67, 0.1));

// availW=900 のとき
// btnW = (900 - 82) / 6 = 818/6 ≈ 136.33
expect(calcBtnW(900, numSlots: 6), closeTo(136.33, 0.1));
```

### UT-02-02: Admin btnW 計算（5スロット）
```dart
// availW=1000 のとき
// btnW = (1000 - 28 - 30 - 22) / 5 = 920/5 = 184.0
expect(calcBtnW(1000, numSlots: 5), closeTo(184.0, 0.1));
```

### UT-02-03: Terminal btnH 計算（3行）
```dart
// availH=600 のとき
// btnH = (600 - 124) / 3 = 476/3 ≈ 158.67
expect(calcBtnH(600, numRows: 3), closeTo(158.67, 0.1));

// availH=400 のとき（clamp下限48の確認）
// raw = (400-124)/3 = 92 → clamp結果は92
expect(calcBtnH(400, numRows: 3), closeTo(92.0, 0.1));
```

### UT-02-04: Admin btnH 正方形キャップ
```dart
// availH=600, btnW=184 のとき
// rawBtnH = (600-84)/2 = 258 → min(258, 184) = 184
expect(calcAdminBtnH(availH: 600, btnW: 184), closeTo(184.0, 0.1));
```

### UT-02-05: Admin extraVPad 計算
```dart
// contentH < availH のとき余剰スペースが上下に均等配分されること
// availH=600, contentH=400 → extraVPad = 100
expect(calcExtraVPad(availH: 600, contentH: 400), closeTo(100.0, 0.1));

// contentH >= availH のとき extraVPad=0
expect(calcExtraVPad(availH=400, contentH=500), equals(0.0));
```

## WT-01: terminal_home_layout_test.dart

Firebase依存サービス（DeviceService, StoreMetaService, StoreConfigService）をモック化する。

### WT-01-01: 全オプション有効時の描画確認
**前提**: `isAdminDevice=false`, `deviceOptions = {全オプション: true}`
**確認**:
- `StoreStrongWarningOverlay` が描画されること
- OverflowErrorが発生しないこと（screen size: 1194×778、Android横向き想定）
- 営業カテゴリのボタン3つが描画されること
- Tournament カテゴリのボタン4つが描画されること
- SideGame カテゴリのボタン1つが描画されること

### WT-01-02: Admin端末の全ボタンアクティブ確認
**前提**: `isAdminDevice=true`, `deviceOptions = {}`
**確認**:
- 全ボタンが `InkWell` の `onTap != null` であること（タップ可能）
- グレーアウトスタイル（`HomeButtonGreyTheme.bg`）のボタンが0件であること

### WT-01-03: オプション未設定時（空Map）の全ボタンアクティブ確認
**前提**: `isAdminDevice=false`, `deviceOptions = {}`
**確認**:
- 全ボタンがアクティブであること（`optionKeys`依存ボタンも含む）

### WT-01-04: 特定オプションのみの場合のグレーアウト確認
**前提**: `isAdminDevice=false`, `deviceOptions = {accounting: true}`（会計のみ）
**確認**:
- 会計カテゴリの3ボタンがアクティブ（`onTap != null`）
- Tournament カテゴリの4ボタンがグレーアウト（`onTap == null`）
- `optionKeys=null` のボタン（ユーザー作成、メニュー追加、入店中一覧）はアクティブ
- `storeManagement=false` なので 営業管理ボタンはグレーアウト

### WT-01-05: Overflow発生しないことの確認（複数スクリーンサイズ）
テストケースごとにスクリーンサイズを指定してOverflowErrorが起きないことを確認:
- iPad Air 11" 横: 1194 × 778
- Redmi Pad SE 11" 横: 1200 × 560（推定）
- 小さめAndroid横: 960 × 520
