# G6: バグ修正 設計記録

## 合わせて実施した G4 追加修正

G4 実装後に発覚した問題（Terminal モード中に AppBar が二重になる）を本セッションで修正した。

### G4追加: AdminHomePage の AppBar を Terminal モード中に非表示

**問題:** Terminal モード中の画面構造が以下になっていた

```
① バナー "AdminデバイスTerminalモード中"
② AdminHomePage AppBar "Terminal"（文字 30px）
③ terminalHomePage AppBar（日付・営業状態）
④ コンテンツ
```

AppBar が2層になり "Terminal" が二重に表示されていた。

**修正:** `adminHomePage.dart` の `build` 内で、`isTerminalMode == true` のとき `appBar: null` を設定。  
`terminalHomePage` は自前の Scaffold+AppBar を持つため、AdminHomePage の AppBar は不要。

**変更ファイル:** `lib/Home/adminHomePage.dart`

## G6 各修正の記録

### G6-01: `print('権限読み込みエラー')` の削除

**なぜ問題か:** `print()` は常に実行され、リリースビルドでもシステムログに出力される。ユーザーには見えないが、コードのクリーンさと情報漏洩リスクの観点から削除すべき。

**修正内容:** 例外 catch ブロック内の `print('権限読み込みエラー')` 1行を削除。エラー状態自体（`_permissionsLoadFailed = true`）は引き続き設定される。

**変更ファイル:** `lib/sideGame/pages/side_game_table_list.dart`

---

### G6-05a: 定期開催トーナメント編集ページへのナビゲーション修正

**なぜ問題か（根本原因）:**

一覧ページは Cloud Function 経由でデータを取得していたが、編集ボタン押下時の `_navigateToEdit()` 関数が **Firestore に直接アクセス** していた。Firestore のセキュリティルールがクライアントからの直接読み取りを禁止している場合、Permission Denied 例外が発生し「定期開催情報を取得できませんでした」が表示されていた。

| 場所 | 修正前 | 修正後 |
|---|---|---|
| `_navigateToEdit()` | `FirebaseFirestore.instance.collection('tournamentRecurrences').doc(id).get()` | 既にロード済みの `_recurrences` リストからデータを取得 |

**修正効果:**
- Firestore への直接アクセスを完全に排除
- ローディングダイアログ不要（同期処理になった）
- `cloud_firestore` import を削除（`recurring_tournament_list_page.dart` で不要になった）

**変更ファイル:** `lib/tournament/scheduling/recurring/recurring_tournament_list_page.dart`

### G6-05b: スケジュール済みトーナメントグリッドのレスポンシブ化

**なぜ問題か:** 編集ページ内の「適用するトーナメント選択」グリッドの列数が `crossAxisCount: 8` と固定されていた。画面幅が狭い端末では各セルが潰れて日付が読めなくなる可能性があった。

**修正内容:** `LayoutBuilder` で利用可能な幅を取得し、最小セル幅 60px を確保しつつ列数を 3〜8 の範囲で自動計算するよう変更。

```dart
// 変更前
crossAxisCount: 8,  // 固定

// 変更後
final crossAxisCount = ((constraints.maxWidth + spacing) / (minCellWidth + spacing))
    .floor()
    .clamp(3, 8);  // 幅に応じて 3〜8 列
```

**影響:** 十分な画面幅（≥ 536px）では従来通り 8 列で表示。狭い端末では自動で少ない列数に折り返す。

**変更ファイル:** `lib/tournament/scheduling/recurring/edit_recurring_tournament_page.dart`

### G6-06: table_home_page ローディング中の AppBar 追加

**なぜ問題か:** `TableHomePage` のローディング中は `Scaffold(body: CircularProgressIndicator())` のみを返しており、AppBar が存在しなかった。読み込みに時間がかかった場合、タイトルも戻るボタンも見えない画面が表示されてしまう。

**修正内容:** ローディング中の Scaffold に `AppBar(title: Text('卓ページ - トーナメント選択'))` を追加。ロード完了後に表示される `TournamentSelectPage` と同じタイトルにして一貫性を保つ。

**変更ファイル:** `lib/Home/table_home_page.dart`
