# 08_意思決定ログ

## 1. 目的

フォルダ再編の作業中に **判断を要した事項** を記録し、後から理由を追えるようにする。
shared カテゴリ追加・ドメイン境界の例外・フォルダ追加などは、必ずここに残す。

## 2. 記録する内容

- shared カテゴリの追加・shared への移動判断
- ドメイン配下の追加フォルダ（例：types/）とその理由
- 1ドメイン＝1設計ドキュメントの例外
- その他、再編方針に関する判断
