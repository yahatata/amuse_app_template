# 対象ファイル・対象箇所の確認（Flutter・`lib/`）

**前提**

- 共通化の対象は `docs/共通化/flutter/01_対象の選定/00_対象の選定.md` の **4項目のみ**（ローディング／保守運用向けエラーログ／ユーザー向け結果出力／確認ダイアログ）。
- **旧資料フォルダは参照していない**。
- **除外したパス**: `lib/to_be_deleted/**`、`lib/scheduledTournament/pages/to_be_deleted_*`（廃止予定のためノイズ）。
- データモデル・フォーマッタのみ等、上記4区分に**明確に当てはまらない**ファイルは本文の表から除外（付録の機械抽出リストにも含めない）。

**凡例**

- **対象箇所（定義）**: **1つのユーザー操作**、**1つの表示分岐**、または **1つの失敗処理**に対して、**独立して認識できる実装のまとまり**。  
  - **ファイル単位ではない**（同一ファイルに同じ論点が複数あれば、対象箇所も複数）。  
  - **コード行単位ではない**（同一 `showDialog` 呼び出しは **1対象箇所**）。  
  - Step3（`03_現状の使用パターンの確認`）では **1対象箇所＝1件** として数える。詳細な例は Step3 の「『1件』および『対象箇所』の定義」を参照。
- **表での記載**: 追跡の手がかりとして、ウィジェット名・メソッド名・`build` 内分岐・`showDialog` 呼び出し等を書く。
- **主分類**: UI部品名ではなく、**表示目的・タイミング・ユーザーに求める行動**で記載。
- **列挙**: 本書は **対象箇所** を列挙する。**ワイルドカード**で複数ファイルをまとめる場合や、**同一ファイル内に複数箇所あり** の場合は **補足** で区別する。

#### 要確認メモ（§2）

- **Flutter と LINE ミニアプリの両方から呼ばれる callable** の例: **`getMenuItems`**（Flutter `MenuItemsManager` と `public/user/index.html`）。補足欄 **共通利用あり**。

## 要確認メモ

- **§2（保守運用時用のエラーログ）** は **Cloud Functions（`functions/src/domains/*`）との対応**を追記済み。細目は **§2 表内の「要確認メモ（§2）」** も参照。
- **`lib/AttendanceManagement/staff_attendance_page_from_terminalHome.dart`**: `e.toString().replaceFirst('Exception: ', '')` は利用者画面だが**例外文字列に近い**。§2 と §3 の境界になりうる。
- **`lib/Accounting/accountingPage.dart`**: `_extractUserFriendlyMessage(e.toString())` は **§3**、同一ファイル内の `'...: $e'` SnackBar は **§2**。混在が多い。

- **`lib/dashboard/*`**: エラー表示が `error` 変数の **ダッシュボード用データ取得失敗**（§2）と、グラフ本体はローディング（§1）が隣接。
