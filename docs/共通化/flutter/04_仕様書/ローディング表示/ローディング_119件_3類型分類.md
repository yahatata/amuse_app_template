## 類型の定義

| 見出し | 仕様上の意味 |
|--------|----------------|
| **読込** | 画面表示時の読込（初回表示・タブ表示など、画面成立に必要なデータ取得の待機が主） |
| **読取** | 画面内ユーザー操作による読取系処理（再取得・照会・試算など、**更新を伴わない**操作が起点） |
| **更新** | 画面内ユーザー操作による更新系処理（CF／Firestore 書込・登録・確定などが起点） |
| **非UI** | サービス・リポジトリ等。**ここにローディング UI を実装する対象ではない**。3 類型は**呼び出し元の UI**に付与。母数に含めるのは非同期の集約点としての**追跡**（Step2 §1.5.2 の `menuItemsManager` と §1.5.3） |

**母数 119** から **`lib/firebase_options.dart` は除外**（Step2 上も母数外）。
