# 会計後調整機能 操作手順書（会計責任者向け）

## この資料で扱うこと

この資料は、会計完了後に請求内容を修正したいときの現場向け手順書です。現在のアプリでは、次の5種類を使い分けます。

- 減額（返金待ち）: 今は返金せず、あとで返す
- 減額（即時返金）: その場で返金まで終わらせる
- 増額（追加徴収待ち）: 今は受け取れず、あとで徴収する
- 増額（即時徴収）: その場で追加徴収まで終わらせる
- 会計前に戻す: 伝票全体を会計前へ戻してやり直す

## 先に確認しておくこと

- 会計後の修正を始める入口は主に `会計後操作`、`要対応の会計`、`会計管理` の3つです。
- 旧画面・旧ボタンは使わないでください。旧導線は `lib/to_be_deleted/` に移されており、現在の運用対象ではありません。
- 会計前に戻す操作は、画面の案内どおり「当日営業日分の伝票だけ」に使ってください。

## 1. `要対応の会計` 画面への入り方と画面構成

### 入り方

1. ホーム画面を開きます。
2. `要対応の会計` を押します。
3. 画面上部のタイトルが `要対応の会計` になっていることを確認します。

### 画面構成

1. 画面上部にタブが2つあります。
2. タブは `日付ごと` と `ユーザー別` です。
3. タブの下に絞り込み chip があります。
4. chip は `すべて`、`未会計`、`追加徴収`、`要返金` の4つです。
5. 一覧には、対象の伝票ごとに状態や金額、操作ボタンが表示されます。

### 画面の見方

1. `日付ごと` は、その営業日の要対応伝票をまとめて見たいときに使います。
2. `ユーザー別` は、同じお客様の対応をまとめて見たいときに使います。
3. `未会計` は、会計が途中で残っている伝票を再開したいときに使います。
4. `追加徴収` は、会計後に不足分を受け取る必要がある伝票だけを見たいときに使います。
5. `要返金` は、会計後に返金が必要な伝票だけを見たいときに使います。

## 2. フィルタ chip の使い分け

| chip | 使う場面 | 画面に出るもの |
|---|---|---|
| `すべて` | 今日の要対応をまとめて確認したいとき | 未会計、追加徴収、要返金をすべて表示 |
| `未会計` | 会計を再開したいとき | 未会計のまま残っている伝票 |
| `追加徴収` | あとでお金を受け取る必要があるとき | `追加徴収待ち` の伝票 |
| `要返金` | あとで返金する必要があるとき | `要返金` の伝票 |

## 3. 即時返金・即時追加徴収の操作手順

即時系は `要対応の会計` ではなく、まず `会計後操作` から入ります。

### 3-1. `会計後操作` 画面を開く

1. ホーム画面を開きます。
2. `会計後操作` を押します。
3. 一覧から対象の伝票を探します。
4. `この伝票を操作` を押します。
5. 画面タイトルが `会計後操作` になっていることを確認します。

### 3-2. 即時返金（減額（即時返金））

1. 操作種類で `減額（即時返金）` を選びます。
2. `既存明細から選ぶ` か `返金内容を手入力` のどちらかで対象を決めます。
3. 既存明細から返す場合は `対象明細を追加` を押して、返金したい明細と数量を指定します。
4. 手入力で返す場合は、画面の案内に従って内容と金額を入力します。
5. `操作メモと精算方法` の欄で `即時精算の方法` を選びます。
6. 必要に応じて `メモ` を入力します。
7. `確認用の文章` で金額と内容を見直します。
8. `減額（即時返金）` ボタンを押します。
9. 画面下に `会計後操作を記録しました（adjustmentId: ...）` が出たら完了です。

### 3-3. 即時追加徴収（増額（即時徴収））

1. 操作種類で `増額（即時徴収）` を選びます。
2. `メニュー・トナメから追加する` か `追加料金を手入力` のどちらかで対象を決めます。
3. メニューから追加する場合は、一覧の `追加` を押して数量を入れます。
4. 手入力で追加する場合は `追加料金の金額（税込）` を入力します。
5. `操作メモと精算方法` の欄で `即時精算の方法` を選びます。
6. 必要に応じて `メモ` を入力します。
7. `確認用の文章` で金額と内容を見直します。
8. `増額（即時徴収）` ボタンを押します。
9. 画面下に `会計後操作を記録しました（adjustmentId: ...）` が出たら完了です。

## 4. 後続徴収（`追加徴収` ダイアログ）の操作手順

後続徴収は、いったん `増額（追加徴収待ち）` で登録したあと、`要対応の会計` から実際の受け取りを記録します。

### 4-1. 追加徴収待ちを作る

1. `会計後操作` を開きます。
2. 対象伝票で `この伝票を操作` を押します。
3. 操作種類で `増額（追加徴収待ち）` を選びます。
4. メニュー追加または手入力で不足分を登録します。
5. 必要に応じて `メモ` を入力します。
6. `増額（追加徴収待ち）` ボタンを押します。
7. 画面下に `会計後操作を記録しました（adjustmentId: ...）` が出たら、要対応一覧に載る状態になります。

### 4-2. 実際に徴収する

1. ホーム画面から `要対応の会計` を開きます。
2. chip を `追加徴収` に切り替えます。
3. 対象伝票の操作ボタンを押します。
4. ダイアログのタイトルが `追加徴収` になっていることを確認します。
5. `対象 adjustment: ...（残額 ¥...）` を確認します。
6. `徴収額（円・税込）` を入力します。
7. `支払方法` を選びます。
8. 必要に応じてメモを入力します。
9. `徴収する` を押します。
10. 画面下に `追加徴収を記録しました（cashActionId: ...）` が出たら完了です。

## 5. 後続返金（`返金` ダイアログ）の操作手順

後続返金は、いったん `減額（返金待ち）` で登録したあと、`要対応の会計` から実際の返金を記録します。

### 5-1. 返金待ちを作る

1. `会計後操作` を開きます。
2. 対象伝票で `この伝票を操作` を押します。
3. 操作種類で `減額（返金待ち）` を選びます。
4. 返したい既存明細または手入力内容を登録します。
5. 必要に応じて `メモ` を入力します。
6. `返金待ちで減額` ボタンを押します。
7. 画面下に `会計後操作を記録しました（adjustmentId: ...）` が出たら、要対応一覧に載る状態になります。

### 5-2. 実際に返金する

1. ホーム画面から `要対応の会計` を開きます。
2. chip を `要返金` に切り替えます。
3. 対象伝票の操作ボタンを押します。
4. ダイアログのタイトルが `返金` になっていることを確認します。
5. `元の支払い` と `対象 adjustment: ...（残額 ¥...）` を確認します。
6. `返金額（円・税込）` を入力します。
7. `返金方法` を選びます。
8. 必要に応じてメモを入力します。
9. `返金する` を押します。
10. 画面下に `返金を記録しました（cashActionId: ...）` が出たら完了です。

## 6. `会計管理` 画面からの reopen 操作と注意事項

reopen は、個別の返金や追加徴収ではなく、伝票全体を会計前の状態に戻してやり直したいときに使います。

### 操作手順

1. ホーム画面から `会計管理` を開きます。
2. `会計完了` タブを開きます。
3. 対象伝票の `会計前に戻す` を押します。
4. ダイアログ `会計前に戻す` が開いたら、案内文を読みます。
5. 必要に応じて `理由メモ（任意）` を入力します。
6. `確認入力` に `戻す` と入力します。
7. `会計前に戻す` を押します。
8. `会計前に戻す処理中...` が表示されます。
9. 完了後に `会計前に戻しました` と表示されたら `OK` を押します。
10. 未会計一覧に戻っていることを確認します。

### 注意事項

1. reopen は、画面の案内どおり当日営業日の伝票だけに使ってください。
2. reopen をすると、その伝票は未会計一覧へ戻ります。
3. reopen 後は必要に応じて、内容を確認してから再会計してください。
4. 単純な金額修正で済む場合は、まず `減額` / `増額` の会計後操作で対応できないかを確認してください。
5. ボタンを押したあと、完了表示が出るまで別操作をしないでください。

## 7. 「どの操作をいつ使うか」判断フロー

| 状況 | 使う操作 | どこから入るか | その場でお金の受け渡しを終えるか |
|---|---|---|---|
| 取りすぎたので今すぐ返す | `減額（即時返金）` | `会計後操作` | 終える |
| 取りすぎたが今は返せない | `減額（返金待ち）` | `会計後操作` → その後 `要対応の会計` | 後で返す |
| 足りないので今すぐ受け取る | `増額（即時徴収）` | `会計後操作` | 終える |
| 足りないが今は受け取れない | `増額（追加徴収待ち）` | `会計後操作` → その後 `要対応の会計` | 後で徴収する |
| 伝票全体を会計前に戻してやり直したい | `会計前に戻す` | `会計管理` の `会計完了` タブ | いったん会計を取り消す |

## 8. 使ってはいけない旧導線

1. 以前の会計後調整の画面・ダイアログは現在の本番運用では使いません。
2. 旧導線はコード上でも `lib/to_be_deleted/` に移されており、現在の運用対象外です。
3. 現場では必ず、`会計後操作`、`要対応の会計`、`会計管理` の3つだけを使ってください。

## 9. よくある確認ポイント

1. 返金待ち・追加徴収待ちを登録しただけでは、お金の受け渡しは終わっていません。`要対応の会計` で完了させてください。
2. 即時返金・即時徴収では、最後に精算方法を選び忘れないでください。
3. reopen は便利ですが、単純な差額修正なら会計後操作の方が履歴を追いやすいです。
4. エラーや不明な状態になった場合は、無理に続けず会計責任者または管理者へ引き継いでください。
