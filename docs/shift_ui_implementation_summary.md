# シフト管理UI実装詳細まとめ

## 概要

新しいシフト管理システムのUI実装を、モックデータを使用して実装しました。主に3つの画面と、募集機能を含むタブ機能を実装しています。

---

## 1. シフト確定ページ (`shiftHomePage.dart`)

### 1.1 基本機能

- **ファイル**: `lib/StaffDate/shiftHomePage.dart`
- **クラス**: `ShiftHomePage` (StatefulWidget)
- **目的**: シフト確定用のメインカレンダー画面

### 1.2 表示制約

- **月表示制限**: 当月と次月のみ表示可能
  - 当月より前の月には移動不可
  - 次月より後の月には移動不可
- **カレンダー行数**: 月によって自動計算（4週間、5週間、または6週間）
  - 計算式: `(月の日数 + 月初日の曜日オフセット) / 7` を切り上げ
  - 例: 31日の月で1日が土曜日の場合 → 6週間

### 1.3 カレンダーセル表示内容

各日付セルには以下の情報を表示：

#### 当月（現在月）
- **日付**: 左上に表示
- **シフト情報**: スタッフ名と時間帯（最大3件まで表示）
- **店休日表示**: 店休日の場合はグレーアウトし「店休日」と表示
- **状態フラグ**: 表示なし（当月は全て最終確定済みの想定）
- **必要十分フラグ**: 表示なし（当月は意味をなさないため）

#### 次月（編集可能月）
- **日付**: 左上に表示
- **必要十分フラグ**: 左上にチェックボックス（手動チェック可能）
- **状態フラグ**: 右上に表示
  - 「中間」: 中間確定済み（青色）
  - 「未処理」: 未処理（オレンジ色）
  - 「最終」: 最終確定済み（緑色）
- **未処理申請バッジ**: 状態が「中間」で未処理申請がある場合、状態フラグの下に件数をバッジ表示
- **シフト情報**: スタッフ名と時間帯（最大3件まで表示）
- **空き時間帯警告**: 営業時間内でスタッフがいない時間帯がある場合、右下に警告アイコン（⚠️）を表示
- **店休日表示**: 店休日の場合はグレーアウトし「店休日」と表示

### 1.4 カレンダーセルサイズ

- **セル高さ**: 画面高さの11.5%（`bodyHeight * 0.1150`）
- **日付フォントサイズ**: 16.1（14 * 1.15）
- **シフト情報フォントサイズ**: 9.2（8 * 1.15）

### 1.5 日付タップ時のダイアログ

- **表示**: `ShiftDateDialog`を表示
- **機能**: カレンダーセルの拡大表示と編集機能

### 1.6 下部タブ機能（次月のみ表示）

次月を表示している場合のみ、画面下部に3つのタブを表示：

#### タブ1: 情報タブ
- **当月表示時**: 当日のシフト情報を表示
  - 日付と状態（最終/中間/未処理）
  - 営業時間
  - 必要人数と現在人数
  - シフト割当一覧（スタッフ名と時間帯）
- **次月表示時**: 全スタッフの合計シフト時間を表示
  - スタッフ名
  - 申請時間（実装予定、現在はモック）
  - シフト時間
  - シフト時間の多い順にソート

#### タブ2: 不足日集計タブ
- **説明文**: 不足日の集計についての説明
- **「不足日を集計」ボタン**: 
  - 押下後は非表示になる
  - 不足日の条件：
    - 必要十分フラグがOFF
    - 空き時間帯がある
- **不足日リスト**: 
  - 日付
  - 必要人数と現在人数
  - 必要十分フラグの状態
  - 空き時間帯（あれば表示）
  - チェックボックス（選択すると募集作成タブに追加）

#### タブ3: 募集作成タブ
- **説明文**: 募集作成についての説明
- **選択された日のカード**: 
  - 日付
  - 営業時間
  - **シフト情報セクション**（灰色背景）:
    - 必要人数と現在人数
    - 必要十分フラグの状態（ON/OFF）
    - シフト割当情報（スタッフ名と時間帯）
    - 空き時間帯（あれば表示）
  - **募集時間帯スライダー**: 
    - 初期状態で営業時間全体のスライダーを1つ表示
    - `RangeSlider`で時間帯を調整可能（30分刻み）
    - 営業時間内でのみ調整可能
    - 削除ボタン（確認ダイアログ付き）
  - **「時間帯を追加」ボタン**: 
    - ダイアログなしで営業時間全体のスライダーを追加
- **「募集を送信」ボタン**: 
  - 選択された日で募集時間帯が設定されている場合のみ表示
  - 送信確認ダイアログを表示

### 1.7 タブのスワイプ機能

- **2つの固定位置**:
  - **位置1（初期）**: カレンダーの下端から8ピクセル下
  - **位置2（展開）**: カレンダー上端とタブ上端が重なる位置（top = 0）
- **スワイプ動作**:
  - 上にスワイプ: 位置2（展開位置）に移動
  - 下にスワイプ: 位置1（初期位置）に戻る
  - 指の動きと同じ方向にタブが追従
  - スワイプ終了時に近い位置にスナップ
- **判定条件**:
  - スワイプ速度が閾値（500 pixels/second）を超えた場合
  - または、ドラッグオフセットが閾値（位置1の30%）を超えた場合
- **アニメーション**: 300msのイージングアニメーション

### 1.8 スクロールバー

- **実装**: すべてのタブに`Scrollbar`を追加
- **設定**: `thumbVisibility: true`で常時表示
- **ScrollController**: 各タブに専用の`ScrollController`を割り当て
  - `_infoTabScrollController`: 情報タブ用
  - `_insufficientDaysTabScrollController`: 不足日集計タブ用
  - `_recruitmentTabScrollController`: 募集作成タブ用

### 1.9 AppBarアクション

- **シフトドラフトボタン**: `ShiftDraftPage`に遷移
- **一括最終確定ボタン**: 対象月の全日を最終確定（確認ダイアログ付き）

### 1.10 空き時間帯検出機能

- **関数**: `_findGapTimeSlots(ShiftDayData dayData)`
- **機能**: 営業時間内でスタッフがいない30分刻みの時間帯を検出
- **表示**: 
  - カレンダーセル右下に警告アイコン
  - 日付ダイアログ内で詳細な時間帯を表示

## 2. 日付ダイアログ (`shiftDateDialog.dart`)

### 2.1 基本機能

- **ファイル**: `lib/StaffDate/shiftDateDialog.dart`
- **クラス**: `ShiftDateDialog` (StatefulWidget)
- **目的**: カレンダーセルの拡大表示と編集

### 2.2 表示内容

- **日付と状態**: 日付と状態フラグ（最終/中間/未処理）
- **営業時間**: 営業時間の表示
- **必要人数**: 必要人数と現在人数
- **必要十分チェックボックス**: 手動チェック可能（次月のみ）
- **最終確定ボタン**: 
  - 位置: 営業時間/必要人数セクションの右側
  - 幅: 画面幅の12%
  - 背景色: `Colors.deepPurple`（変更ボタンと同じ）
- **シフト割当一覧**: 
  - スタッフ名と時間帯
  - 編集ボタン（時間変更）
  - 削除ボタン（確認ダイアログ付き）
- **空き時間帯セクション**: 
  - 空き時間帯がある場合のみ表示
  - 時間帯ごとに赤背景のボックスで表示
  - 警告アイコン付き
- **未処理申請表示**: 
  - 未処理申請がある場合、「未処理申請: ○件」と表示
  - 操作は不可（ドラフトページでのみ操作可能）

### 2.3 編集機能

- **即座に反映**: チェックボックス操作、割当編集・削除は即座に反映（「変更する」ボタン不要）
- **時間変更**: 時間選択ダイアログで時間を変更可能
- **削除**: 確認ダイアログを表示してから削除

### 2.4 最終確定機能

- **個別最終確定**: ダイアログ内の「最終確定」ボタンでその日を最終確定
- **自動チェック**: 最終確定時に必要十分チェックボックスも自動でチェック

## 3. ドラフトページ (`shiftDraftPage.dart`)

### 3.1 基本機能

- **ファイル**: `lib/StaffDate/shiftDraftPage.dart`
- **クラス**: `ShiftDraftPage` (StatefulWidget)
- **目的**: 中間確定用のドラフト編集画面

### 3.2 日付選択

- **横スクロール**: その月の全日を日付ボタンで横スクロール表示
- **店休日表示**: 店休日はグレーアウト表示
- **選択状態**: 選択された日付はハイライト表示

### 3.3 申請カード表示

選択された日付の申請をカード形式で表示：

#### カード構成
- **ヘッダー**: 
  - スタッフ名（左側）
  - **申請時間**（staff 最新希望 = `shiftRequests.startMinute` / `endMinute`、緑色）
  - **割当時間**（Admin local state 初期値 = 最新申請、黒色。スライダー操作でのみ変化）
  - チェックボックス（右上、中間確定用）
- **営業時間表示**: 
  - 営業時間の表示（黒色）
  - 説明文（右側）:
    - 「中間確定: 選択した申請を中間確定します」
    - 「必要十分チェック: 不足日の募集などに使う判断材料。必要十分チェックの自動判定人数に達していなくとも管理者の裁量で手動チェックが可能」
    - 「カードを左にスワイプして申請を却下することが可能」
- **割当時間スライダー**: 
  - `RangeSlider`で時間帯を調整
  - ラベル: 「割当時間: XX:XX - XX:XX」（24ポイント、太字、黒色）
  - スライダー範囲: **最新申請時間**（`startMinute` / `endMinute`）内でのみ調整可能
  - 最小間隔: 1時間
  - 両端の時間表示: スライダーの左右に開始時間と終了時間を表示
- **`originalStartMinute` / `originalEndMinute`**: 初回申請 audit 用。**UI 表示・スライダー制限には使わない**

### 3.4 スライダー機能

- **RangeSlider**: 開始時間と終了時間を1つのスライダーで操作
- **制約**: 
  - **最新申請時間**内でのみ調整可能
  - 最小間隔1時間を確保
  - 両端が重なった場合はそれ以上進めず、戻す方向には動かせる

### 3.5 却下機能

- **スワイプ操作**: カードを左にスワイプして却下
- **確認ダイアログ**: 却下前に確認ダイアログを表示
- **表示制限**: 中間確定済みまたは却下済みの申請は表示しない

### 3.6 下部アクション

- **「選択して中間確定」ボタン**: チェックされた申請を中間確定
- **「必要十分（手動）」チェックボックス**: その日の必要十分フラグを手動で設定

### 3.7 説明文

カードと日付選択の間に3つの説明文を表示：
1. 「中間確定: 選択した申請を中間確定します」
2. 「カードを左にスワイプして申請を却下することが可能」
3. 「必要十分チェック: 不足日の募集などに使う判断材料。必要十分チェックの自動判定人数に達していなくとも管理者の裁量で手動チェックが可能」

## 4. データ構造

### 4.1 ShiftDayData

```dart
class ShiftDayData {
  final DateTime date;
  final BusinessHours businessHours;
  final int requiredCount;
  final bool isSufficient;
  final bool isInterimConfirmed;
  final bool isFinalized;
  final List<ShiftAssignment> assignments;
  final int pendingRequestCount; // 未処理申請数
  
  // currentCountはassignments.lengthから派生（別フィールドとして保存しない）
}
```

### 4.2 ShiftAssignment

```dart
class ShiftAssignment {
  final String staffId;
  final String staffName;
  final String startTime; // "HH:MM"
  final String endTime; // "HH:MM"
}
```

### 4.3 ShiftRequest (ドラフトページ用)

```dart
class ShiftRequest {
  final String requestId;
  final String staffId;
  final String staffName;
  final String date; // "YYYY-MM-DD"
  final String startTime; // "HH:MM"
  final String endTime; // "HH:MM"
  final String? originalStartTime; // 元の申請時間
  final String? originalEndTime; // 元の申請時間
  final String status; // 'pending' | 'interim_confirmed' | 'final_confirmed' | 'rejected'
}
```

### 4.4 RecruitmentTimeSlot

```dart
class RecruitmentTimeSlot {
  final String startTime; // "HH:MM"
  final String endTime; // "HH:MM"
}
```

### 4.5 BusinessHours

```dart
class BusinessHours {
  final String open; // "HH:MM"
  final String close; // "HH:MM"
  final bool isClosed;
}
```

## 5. ユーティリティ関数

### 5.1 時間変換

- **`_timeToMinutes(String timeStr)`**: "HH:MM"形式の文字列を0:00からの分数に変換
- **`_minutesToTime(int minutes)`**: 分数を"HH:MM"形式の文字列に変換
- **24:00の扱い**: 1440分として扱う（24:xxは禁止）

### 5.2 空き時間帯検出

- **`_findGapTimeSlots(ShiftDayData dayData)`**: 営業時間内でスタッフがいない30分刻みの時間帯を検出
- **戻り値**: `List<({int start, int end})>`（開始分数と終了分数のレコード）

## 6. モックデータ

### 6.1 生成ルール

- **当月**: 全て最終確定済み（`isFinalized: true`）、中間確定なし、チェックボックスなし
- **次月**: 様々な状態を混在
  - 1-10日: 中間確定済み
  - 11-15日: 未処理
  - 16日以降: シフト割当があれば中間確定済みで未処理申請が3件、なければ未処理（未処理申請が3件）
  - 10の倍数日: 申請なし（`assignments: []`）
  - 一部の日: 空き時間帯が発生するパターンを含む

### 6.2 営業時間

- **デフォルト**: 09:00 - 22:00
- **店休日**: `isClosed: true`

## 7. 状態管理

### 7.1 ローカル状態

- **`_mockShiftData`**: 日付ごとのシフトデータ（Map形式、key: "YYYY-MM-DD"）
- **`_insufficientDays`**: 不足日のdateKeyリスト
- **`_recruitmentSlots`**: 募集時間帯（dateKey -> 時間帯リスト）
- **`_isTabExpanded`**: タブの展開状態
- **`_dragOffset`**: スワイプ中の一時的なオフセット

### 7.2 即座反映

- ダイアログ内での編集（チェックボックス、割当編集・削除）は即座に反映
- 別途「変更する」ボタンは不要

## 11. 主要な実装ポイント

1. **モックデータベース**: 実際のデータ連携前にUIの動作確認が可能
2. **状態管理**: ローカル状態で即座に反映される編集機能
3. **スワイプ機能**: 2つの固定位置にスナップするタブ展開機能
4. **スライダー操作**: 申請時間内でのみ調整可能な時間帯スライダー
5. **空き時間帯検出**: 営業時間内のスタッフ不在時間帯を自動検出
6. **スクロールバー**: 各タブに専用のScrollControllerを割り当てて競合を回避
