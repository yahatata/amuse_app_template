# 環境変数・Secret Manager 移行 改善概要

## なぜこの改善が必要か

- Firebase デプロイ時に `.env` が読み込まれ、その内容で本番の環境変数が上書きされる
- 一部の関数だけデプロイすると、デプロイした関数だけが `.env` で更新され、関数間で値が食い違う
- その結果、意図しないエラー（例：QR_SECRET_KEY 未設定、LINE_CHANNEL_ACCESS_TOKEN の齟齬）が発生する
- 本番で同様の事象が起きることは避けたい

## どのように改善を試みるか（現時点の案）

- **Secret Manager（defineSecret）への移行**：API キー・トークンなどを `.env` ではなく Secret Manager で管理する
- デプロイでは `.env` を参照しないため、デプロイによる上書きを防ぐ
- 詳細は `docs/LINEミニアプリ、LIFF/` 内の関連ドキュメントを参照
