## 3. `amuse-admin` リポジトリの初期セットアップ

新規 AI セッションで `amuse-admin` を実装する際に実行する初期コマンド:

```bash
# Next.js プロジェクト作成
npx create-next-app@latest amuse-admin \
  --typescript \
  --tailwind \
  --app \
  --src-dir \
  --import-alias "@/*"

cd amuse-admin

# shadcn/ui の初期化
npx shadcn@latest init

# Firebase SDK
npm install firebase firebase-admin
npm install firebase-functions

# その他ユーティリティ
npm install date-fns  # 日付処理
npm install @tanstack/react-table  # テーブル
```

### Firebase 設定

```bash
# Firebase プロジェクトを amuse-central-monitoring に設定
firebase use amuse-central-monitoring

# Hosting・Functions の初期化
firebase init hosting functions
```

新規 AI セッションが `amuse-admin` の実装を始める前に以下を確認する:

## 8. ローカル開発・デバッグの方法

### 開発サーバーの起動

```bash
cd amuse-admin
npm run dev
```

ブラウザで `http://localhost:3000` を開くと管理アプリが表示される。  
コードを変更するとブラウザが自動で更新される（Hot Reload）。

### デバッグの方法

#### ① ブラウザの DevTools（メイン手段）

1. Chrome で `http://localhost:3000` を開く
2. `F12`（または右クリック → 「検証」）で DevTools を開く
3. **Console タブ**: エラーメッセージ・`console.log` の出力
4. **Network タブ**: Firebase へのリクエスト・レスポンス確認

> 9 割のデバッグはここで完結する。

#### ② Cursor のターミナル出力

`npm run dev` を実行しているターミナルに、サーバーサイド（Functions / API Routes）のエラーが表示される。  
Firestore 接続エラーや認証エラーはここに出ることが多い。

#### ③ Cursor でブレークポイントを使う場合

`amuse-admin/.vscode/launch.json` を以下の内容で作成:

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Next.js デバッグ",
      "type": "node",
      "request": "launch",
      "runtimeExecutable": "npm",
      "runtimeArgs": ["run", "dev"],
      "port": 9229,
      "serverReadyAction": {
        "pattern": "started server on .+, url: (https?://.+)",
        "uriFormat": "%s",
        "action": "openExternally"
      }
    }
  ]
}
```

Cursor 左サイドバーの「実行とデバッグ」（▶️アイコン）から「Next.js デバッグ」を選んで起動する。  
コード行番号の左をクリックするとブレークポイントを設置できる。

### Android Studio は使わない

Android Studio は Flutter / Android 専用の IDE。  
Next.js のデバッグには対応していないため使用しない。  
**Next.js は Cursor（または VS Code）+ ブラウザ DevTools でデバッグする**。

## 9. 完了の定義（Phase 1）

以下がすべて満たされた状態を Phase 1 完了とする:

- [ ] 管理者アカウントでログインできる
- [ ] HOME に全有効店舗のエラー件数が表示される
- [ ] 特定の店舗のエラー一覧が表示・フィルターできる
- [ ] エラーに「対応済み」フラグを付けられる
- [ ] 重要度ルールを追加・変更・無効化できる
- [ ] 新しい重要度 5 のエラーが発生したとき LINE または メールに通知が届く
- [ ] 店舗を追加登録できる
