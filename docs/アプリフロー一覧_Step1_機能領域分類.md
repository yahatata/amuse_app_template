# アプリフロー一覧 - Step 1: 機能領域分類

**作成日**: 2025-01-XX  
**目的**: 主要機能領域をMECEに分類し、フロー構造を整理

---

## 1. 機能領域の分類（MECE構造）

### 1.1 認証・デバイス管理領域
- **目的**: アプリの初期化、デバイス登録、権限管理
- **主要画面**: 
  - デバイス登録画面
  - デバイス管理画面
  - システム設定画面
- **主要機能**:
  - デバイス登録・削除
  - デバイスオプション設定（権限付与）
  - デバイスステータス管理（active/blocked/retired）

### 1.2 ユーザー管理領域
- **目的**: 顧客（ユーザー）のアカウント管理、入退店管理
- **主要画面**:
  - ユーザー作成画面
  - ユーザーログイン画面（QR/手動）
  - 入店中ユーザー一覧画面
  - ユーザーアクションホーム（各種操作メニュー）
- **主要機能**:
  - ユーザーアカウント作成
  - QRコードチェックイン/チェックアウト
  - 手動チェックイン/チェックアウト
  - 入店中ユーザー一覧表示
  - ユーザー情報参照（プロフィール、注文履歴、トーナメント履歴等）

### 1.3 トーナメント管理領域
- **目的**: ポーカートーナメントの企画・運営・管理
- **主要画面**:
  - トーナメントテンプレート作成・編集画面
  - ブラインドテンプレート作成・編集画面
  - 定期開催トーナメント設定画面
  - 単発トーナメント作成画面（直接入力/カレンダー）
  - スケジュール済みトーナメント一覧画面
  - トーナメントホーム画面（実行中）
  - 卓詳細画面
  - ブラインドタイマー画面
  - プライズ確定画面
  - 順位確定画面
- **主要機能**:
  - テンプレート管理（作成・編集・アーカイブ）
  - ブラインド構造管理
  - 定期開催設定（曜日・間隔・終了日）
  - 単発トーナメント作成
  - 参加者登録
  - 座席管理（着席・退席・リシート）
  - リエントリー・アドオン処理
  - バースト処理
  - プライズ確定
  - 順位確定
  - トーナメント終了処理

### 1.4 会計管理領域
- **目的**: 顧客の会計処理、支払い管理、会計後調整
- **主要画面**:
  - 会計管理画面
  - 会計履歴画面
  - 会計後調整画面
  - 支払い分割テスト画面
- **主要機能**:
  - 会計開始
  - 会計前編集（注文追加・削除・変更）
  - 会計確定
  - 支払い分割計算（複数支払い方法対応）
  - 会計後調整（追加徴収・減額・返金・キャンセル・再オープン）
  - 会計履歴参照
  - 顧客別会計詳細参照

### 1.5 注文管理領域
- **目的**: メニュー管理、注文受付、キッチン管理
- **主要画面**:
  - カテゴリー選択画面
  - メニュー一覧画面
  - メニュー編集画面
  - 注文管理画面（キッチン画面）
- **主要機能**:
  - メニューアイテム作成・編集・削除
  - 売り切れ設定
  - 注文受付（カテゴリー→メニュー→数量→確定）
  - 注文ステータス管理（準備中・提供中・提供済み）
  - 注文編集・キャンセル
  - 注文履歴参照

### 1.6 サイドゲーム管理領域
- **目的**: サイドゲーム（カジノゲーム）の運営管理
- **主要画面**:
  - サイドゲームテーブル一覧画面
  - サイドゲームテーブルホーム画面
- **主要機能**:
  - テーブル選択・ゲーム開始
  - 参加者登録（座席指定）
  - Tip管理（参照・引き出し・預入）
  - Chip購入
  - 退席処理
  - ゲーム終了処理

### 1.7 勤怠管理領域
- **目的**: スタッフの勤怠記録、給与計算
- **主要画面**:
  - スタッフ打刻画面（QR/手動）
  - 全スタッフ勤怠画面
  - スタッフ勤怠詳細画面
  - 勤怠修正申請画面
- **主要機能**:
  - QRコード打刻（出勤・退勤）
  - 手動打刻（出勤・退勤）
  - 勤怠記録参照（日次・月次）
  - 勤怠修正申請・承認・却下
  - 給与計算（月次自動計算）
  - 勤怠統計（勤務時間・深夜時間・勤務日数）

### 1.8 シフト管理領域
- **目的**: スタッフのシフト要請・承認・管理
- **主要画面**:
  - シフト要請画面（カレンダー形式）
  - シフト承認画面
  - シフト一覧画面（カレンダー形式）
- **主要機能**:
  - シフト要請送信（複数スタッフ・複数日一括）
  - シフト承認・却下（一括処理対応）
  - シフト一覧表示（カレンダー形式）
  - シフト自動クリーンアップ（却下シフトの自動削除）

### 1.9 スタッフ管理領域
- **目的**: スタッフアカウント管理、時給・銀行情報管理
- **主要画面**:
  - スタッフ作成画面
  - スタッフ一覧画面
  - スタッフ詳細画面
- **主要機能**:
  - スタッフアカウント作成（QRコード生成・メール送信）
  - スタッフ一覧表示
  - 時給設定
  - 銀行情報設定
  - スタッフ情報編集

### 1.10 ダッシュボード・分析領域
- **目的**: 売上分析、データ可視化
- **主要画面**:
  - ダッシュボードホーム画面
  - 年間比較画面
  - カテゴリ別詳細画面
  - 支払い方法別詳細画面
  - 日次推移画面
- **主要機能**:
  - 月次売上表示（総売上・来店数・平均客単価・最高/最低日）
  - 年間比較グラフ（直近6ヶ月）
  - カテゴリ別売上分析
  - 支払い方法別売上分析
  - 日次推移グラフ
  - カテゴリ別アイテム詳細分析

### 1.11 システム設定・運用領域
- **目的**: システム全体の設定、データ管理、運用支援
- **主要画面**:
  - システム設定画面
- **主要機能**:
  - 一時テーブル作成
  - データ移行（settledBills移管）
  - ダミーデータ生成（テスト用）
  - 全テーブルリセット
  - 全サイドゲームリセット
  - 閉店クリーンアップ（activeStays全削除）

## 2. フロー構造の分類

### 2.1 初期化フロー
- アプリ起動 → デバイス登録状態チェック → 適切なホーム画面表示

### 2.2 ユーザー操作フロー
- 入店 → 注文・トーナメント参加・サイドゲーム参加 → 会計 → 退店

### 2.3 スタッフ操作フロー
- 打刻 → 業務（注文管理・会計・トーナメント運営等） → 打刻

### 2.4 管理者操作フロー
- システム設定 → 各種管理（スタッフ・シフト・トーナメント企画等） → 分析・レポート確認

### 2.5 自動処理フロー
- 夜間バッチ（売上再計算・整合性チェック・給与計算）
- 定期トーナメント自動生成
- シフト自動クリーンアップ
