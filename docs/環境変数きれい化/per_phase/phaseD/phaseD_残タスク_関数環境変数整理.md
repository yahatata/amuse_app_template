# phaseD 残タスク: 関数環境変数整理

作成日: 2026-04-01

## 1. 現在状況

- Cloud Console 上で、関数に旧環境変数が残っていることを確認済み。
- 現在、関数ごとの環境変数実態をコマンドで棚卸し中。

## 2. 確認コマンド完了後に実施すること

1. 棚卸し結果を「残すキー / 削除候補キー / 要判断キー」に分類する。
2. 削除候補キーは、`functions/src` 実コード参照と突合して未参照であることを再確認する。
3. 関数別に削除対象を確定し、実行順を決める。
4. 削除実施前にロールバック方針を固定する。
   - どの関数で何を戻すか
   - どのコマンドで復旧するか
5. 削除を実行する（段階実施を基本とする）。
6. 削除後に再確認を行う。
   - Functions 設定上から該当環境変数が消えていること
   - 対象関数の実行でエラーが増えていないこと
   - Secret Manager 参照経路が維持されていること
7. 結果を `phaseE` の changeSpec / ログへ引き継ぐ。

## 3. 実施時の注意

- 旧環境変数の削除は、必ず「未参照確認」とセットで行う。
- 一括削除ではなく、失敗時の切り戻しができる粒度で進める。
- phaseD で移行した `line-config` / `task-endpoints` / `business-secrets` の利用経路を壊さない。
